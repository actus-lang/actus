# Repository boundaries

Work only in the repository named by the task. A compiler limitation belongs
in the Actus repository; an application implementation belongs in its own
repository.

Before changing a second repository, stop at the boundary and obtain an
explicit scope change. Do not copy project-specific code, terminology, or
architecture into the language compiler guide.

Preserve user changes, do not reset or delete uncommitted work, and do not
replace an existing implementation with a temporary workaround.
