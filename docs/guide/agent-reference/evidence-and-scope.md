# Evidence and scope

Match each statement to the evidence that supports it.

- Parser support requires parser evidence.
- Semantic support requires accepted and rejected semantic cases.
- Native behavior requires object or executable evidence.
- Runtime behavior requires an execution result.
- Performance requires a reproducible benchmark.
- Hardware behavior requires a target-specific measurement.
- Public API behavior requires facade, documentation, and regression coverage.

A passing check does not establish a different layer's behavior. Keep design
material, implemented behavior, target boundaries, and future work separate in
source and documentation.
