# Agent reading order

Before changing Actus code:

1. read `AGENTS.md` and the relevant contribution instructions;
2. inspect `git status --short --branch`;
3. read the human handbook page for the language or API involved;
4. locate the canonical source, facade, tests, ADR, and roadmap;
5. classify the request as implemented, bounded, design-only, or new;
6. identify the ownership, layout, visibility, target, and failure invariants;
7. choose the narrowest validation command.

Use the human handbook for language meaning. Use this category for change
workflow, repository boundaries, and evidence decisions.
