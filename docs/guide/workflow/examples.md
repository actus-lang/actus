# Examples

Examples are executable descriptions of current Actus usage. Each example
should state its package setup, imports, runtime profile, and expected command.

Use the smallest example that demonstrates one concept. Keep examples beside
the handbook page that introduces them, and link to the maintained repository
example when the full workflow already exists.

Remove or label examples that require a design-only feature. Do not use an
example to imply a target, runtime, or standard-library capability that its
manifest does not select.
