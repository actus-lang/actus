# Phase 39 Wire Acceptance Evidence — 2026-10-08

This record covers transport-neutral host and freestanding evidence for
`std::wire`. It does not claim physical serial, USB, CAN, WebSocket, board, or
microcontroller behavior.

## Environment

- Repository: Actus
- Compiler profile: installed Actus compiler built from this checkout
- Native test target: host platform for executable fixtures
- Freestanding object target: `x86_64-unknown-uefi`
- Runtime storage: caller-owned bounded buffers; no Wire heap or filesystem
  operation

## Commands and results

```text
CARGO_BUILD_JOBS=1 CARGO_TARGET_DIR=/tmp/actus-wire-gate39-target \
  cargo test --test std_wire_native -- --test-threads=1
7 passed, 0 failed
```

The native suite covers deterministic CRC, valid and malformed frame handling,
incremental parsing, endpoint validation, sequence duplicate/stale rejection,
fragment reassembly, unused-module reachability, and the freestanding object
check. The freestanding fixture accepts Wire type metadata without importing a
host output, filesystem, or socket service.

```text
CARGO_BUILD_JOBS=1 CARGO_TARGET_DIR=/tmp/actus-wire-gate39-target \
  cargo test --test examples_cli -- --test-threads=1
12 passed, 0 failed
```

The executable examples include the protocol path and the optional hosted
`wire://` endpoint path. The examples select no physical transport.

## Security boundary

The initial profile is unauthenticated. CRC16-CCITT detects accidental
corruption only. Encryption, authentication, key management, authorization,
and transport retry policies remain separate future profiles and are not
implied by these results.
