# E1880: bundled toolchain component is missing

Freestanding ARM programs are linked with the linker and the compiler runtime
that ship with the compiler, so that the same toolchain links them on every
machine (ADR-0041, ADR-0105). This error means a part of that bundle is not
there. It is an error of the installation and of no file of the project, so it
prints as `error[E1880]: message`, with no path. The message is one of:

```text
error[E1880]: bundled component `ld.lld` is missing for freestanding target `thumbv7em-none-eabi`; run scripts/bootstrap_llvm.sh or scripts/bootstrap_llvm.ps1
error[E1880]: bundled component `libclang_rt.builtins.a` is missing for freestanding target `thumbv7em-none-eabi`; run scripts/bootstrap_llvm.sh or scripts/bootstrap_llvm.ps1
error[E1880]: bundled component `libclang_rt.builtins.a` is missing at `<path>`
error[E1880]: cannot read bundled toolchain manifest `<path>`: <reason>
error[E1880]: cannot parse bundled toolchain manifest `<path>`: <reason>
error[E1880]: installed runtime archive is missing under `<directory>`
```

## Cause

A project selects a freestanding ARM target, such as `target =
"thumbv7em-none-eabi"`, and names no linker in `linker` or `ACTUS_LINKER`, and
the toolchain directory of the compiler, which holds
`share/actus/toolchain.json` and `lib/actus/bin`, lacks `ld.lld` or the
compiler-runtime builtins that the target needs, or its manifest cannot be
read. The last message is the one of a hosted link whose installation has no
runtime archive under `lib/actus/runtime/<host triple>`. A program cannot
trigger this error on purpose, so it has no example.

## Fix

Run `scripts/bootstrap_llvm.sh` (or `scripts/bootstrap_llvm.ps1` on Windows) to
install the bundled toolchain, or install the compiler again from a complete
release.
