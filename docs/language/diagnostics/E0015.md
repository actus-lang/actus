# E0015: open import outside an import block

`open` adds the names of an imported module to the current scope. ADR-0087
requires the opening to be visible in the import block, so a standalone
`import open module;` is rejected. The error points at the import statement.

## Example

```actus fails=E0015
import open std::time;

verb main() {
}
```

## Fix

Write the import as a block and put `open` inside it.

```actus compiles
import { open std::time };

verb main() {
}
```
