# E1840: public declaration has no documentation

Every `open` declaration of a package is public, and strict mode (`--strict`,
ADR-0041) requires it to have a `"""` block docstring. The check covers the
`open` verbs, external verbs, structs and their fields, packs and their
fields, serialization contracts, enums and their variants, roles and their
methods, performances and their methods, and the facade exports `open name;`.
A declaration that is not `open` is private and needs no documentation. A
docstring that is empty or holds only blanks counts as missing. The message
names the declaration, as in `verb answer: missing or empty block docstring`,
and the error points at the declaration.

`actus check`, `actus build` and `actus test` check every source file of the
package, not only the file that holds `main`, and print the findings of each
file before the run fails. Without `--strict` the documentation is not checked.

## Example

```actus fails=E1840,strict
open verb answer() -> Int {
    return 42;
}

verb main() {
}
```

## Fix

Write a `"""` block docstring directly above the declaration. It states what
the declaration is for and, where they apply, its ownership roles, its return
value and its error variants. Strict mode does not check that content yet.

```actus compiles strict
"""Return the constant answer 42 as an integer value."""
open verb answer() -> Int {
    return 42;
}

verb main() {
}
```
