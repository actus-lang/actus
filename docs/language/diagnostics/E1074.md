# E1074: pack leaves bits uncovered

The fields of a pack must account for every bit of the store (ADR-0026). A
gap would be padding that nobody named, and its value would be left to chance.
Unused bits are written as an explicit field called `_reserved`, which may
give them a default value. The message gives the first and the end of the
uncovered range. The error points at the pack.

## Example

```actus fails=E1074
pack Flags {
    erg storage: u8;
    layout little;
    fields {
        erg enabled: u1 at 0;
    }
}

verb main() {
}
```

## Fix

Add a `_reserved` field that covers the gap.

```actus compiles
pack Flags {
    erg storage: u8;
    layout little;
    fields {
        erg enabled: u1 at 0;
        abs _reserved: u7 at 1 = 0;
    }
}

verb main() {
}
```
