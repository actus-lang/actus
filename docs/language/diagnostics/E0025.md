# E0025: invalid integer type

Integer types are `u1` to `u128` and `i1` to `i128`, and the same names are
the suffixes of literals, such as `255u8`. ADR-0026 sets this range. The
lexer reports this error for a name or suffix made of `u` or `i` and a number
outside it, such as `u0` or `u129`.

## Example

```actus fails=E0025
verb main() {
    erg wide: u129 = 5;
}
```

```actus fails=E0025
verb main() {
    erg zero = 5u0;
}
```

## Fix

Use a width from 1 to 128, and a value that fits it.

```actus compiles
verb main() {
    erg wide: u128 = 5;
}
```

```actus compiles
verb main() {
    erg small = 5u8;
}
```
