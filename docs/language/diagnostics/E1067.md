# E1067: cannot infer which Result is built

`Ok(value)` and `Err(value)` build a `Result[T, E]`, but the value alone does
not say what `T` and `E` are. The compiler takes them from the type that the
context expects, such as a declared binding type or the return type of the
verb. When there is no such type the constructor cannot be resolved. The
message shows the spelling that always works, `Result[T, E].Ok(...)`. The
error points at the constructor.

## Example

```actus fails=E1067
verb main() {
    erg r = Ok(1);
}
```

## Fix

Give the binding its type, or name the full `Result` type at the constructor.

```actus compiles
verb main() {
    erg r: Result[Int, Int] = Ok(1);
}
```

```actus compiles
verb main() {
    erg r = Result[Int, Int].Ok(1);
}
```
