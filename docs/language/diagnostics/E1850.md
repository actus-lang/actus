# E1850: source file is above the preferred size

A source file has more than 500 code lines, which is the preferred size of a
file. Strict mode (`--strict`, ADR-0041) counts the code lines of a file, that
is the lines that are neither blank nor a comment, and reports the first limit
the file crosses: `E1850` above 500, `E1851` from 600 and `E1852` above 800.
Without `--strict` the size of a file is not checked. The message names the
count, as in `source file has 502 code lines; preferred limit is 500`, and the
report points at the start of the file. Strict mode fails the run, so the
finding is an error.

## Example

The comment `# catalog: repeat N` stands for N copies of the lines up to
`# catalog: end`, with `{n}` replaced by the copy's number. The example is 250
functions `step_001` to `step_250`, 2 code lines each, and `main`, which make
502 code lines.

```actus fails=E1850,strict
# catalog: repeat 250
verb step_{n}() {
}
# catalog: end
verb main() {
}
```

## Fix

Split the file by responsibility: move the declarations that belong together
into a module of their own, so that each file stays below the limit.

When a large file is one cohesive unit that splitting would damage, mark it
with `meta limitless("file")` at its beginning (ADR-0048). The exception is
then visible in the source and in review, instead of hidden in a comment.

```actus compiles strict file=src/main.act
import steps;

verb main() {
}
```

```actus file=src/steps/steps.act
"""Re-export the first step moved out of the large file."""
open first;
```

```actus file=src/steps/first.act
"""Do nothing, as the first step that was moved out of the large file."""
open verb first_step() {
}
```
