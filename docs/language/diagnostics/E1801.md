# E1801: package name is not a valid identity

The `name` of `[package]` is the namespace of the package: a name that other
packages import and that the compiler uses to tell packages apart (ADR-0041).
It must start with a letter or `_`, hold only letters, digits, `_` and `-`
(`-` reads as `_`), and not be `builtin` or `std`, which belong to the
compiler. The same name must not name two packages of one build. The report
names `Actus.toml` and the line and column of the name, and the code is the
same with and without `--strict`.

## Example

A name that starts with a digit:

```toml fails=E1801 file=Actus.toml
[package]
name = "1app"
version = "0.1.0"
```

```actus file=src/main.act
verb main() {
}
```

A name that is reserved for the compiler:

```toml fails=E1801 file=Actus.toml
[package]
name = "std"
version = "0.1.0"
```

```actus file=src/main.act
verb main() {
}
```

## Fix

Choose a name that starts with a letter and is not reserved.

```toml compiles file=Actus.toml
[package]
name = "app"
version = "0.1.0"
```

```actus file=src/main.act
verb main() {
}
```
