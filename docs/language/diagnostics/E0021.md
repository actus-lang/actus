# E0021: unsupported capability

`meta capability("...")` names a native feature that a verb needs from the
target. The names come from a closed registry in the compiler, such as
`posix.cloexec`, `posix.create_exclusive`, `unix.rename_atomic` and
`windows.replace_file`. ADR-0096 says the parser rejects every other name, so
a requirement that the compiler cannot check is never accepted. The error
points at the string.

## Example

```actus fails=E0021
meta capability("fly")
verb main() {
}
```

## Fix

Use a name from the registry.

```actus compiles
meta capability("posix.cloexec")
verb main() {
}
```
