# E1090: cast between types that are not both integers

`value as Type` is a checked conversion between integer types (ADR-0042). It
does not turn a `Bool` into a number, a number into a `Bool` or a float, or a
struct into anything. Each of these changes the meaning of a value, and Actus
asks for that to be written out. The message names the source and the target
type. The error points at the cast.

## Example

```actus fails=E1090
verb main() {
    erg flag: Bool = true;
    erg n = flag as u8;
}
```

```actus fails=E1090
verb main() {
    erg n: Int = 1;
    erg flag = n as Bool;
}
```

## Fix

Write the conversion that the program means, with a condition or a
comparison, and keep `as` for integers.

```actus compiles
verb main() {
    erg flag: Bool = true;
    erg n: u8 = if flag { 1u8 } else { 0u8 };
}
```

```actus compiles
verb main() {
    erg n: Int = 1;
    erg flag: Bool = n != 0;
}
```
