# E1121: call needs an effect that the caller does not declare

`meta effect(...)` names the operational properties of a verb, such as
`filesystem` or `blocking` (ADR-0091). A verb that calls another verb with
an effect carries that effect too. Its own `meta effect` must list it, so the
effect stays visible in every signature up the call graph. The error points at
the call. The message names the callee and the missing effect.

## Example

```actus fails=E1121
meta effect("filesystem")
verb load() -> Int {
    return 0;
}

verb main() {
    erg value = load();
}
```

## Fix

Declare the effect on the caller.

```actus compiles
meta effect("filesystem")
verb load() -> Int {
    return 0;
}

meta effect("filesystem")
verb main() {
    erg value = load();
}
```
