# E0007: unsupported target platform

`meta target("...")` keeps a declaration only on some platforms. The string
must be `unix`, `posix` or `windows`. The compiler does not know other names,
such as an operating system or a CPU, and it does not guess what they mean.
ADR-0089 lists the three selectors. The error points at the string.

## Example

```actus fails=E0007
meta target("linux")
verb main() {
}
```

## Fix

Use one of the three selectors. `unix` covers Linux and the other Unix
systems.

```actus compiles
meta target("unix")
verb main() {
}
```
