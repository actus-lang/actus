# E1103: module directory cannot be inspected

The compiler lists a module directory to find the sibling files and the child
modules of the module. This error means the operating system refused the
listing. The message names the directory and the system's reason, such as
`Permission denied`.

## Cause

The directory exists and the compiler can reach its facade, but it cannot
read the list of its entries. The usual cause is a directory that has the
search permission and lacks the read permission for the user who runs the
compiler, for example mode `311` on a Unix system. A directory that cannot be
searched at all is reported as E1101, because the facade file is then not
found.

A program cannot trigger this error on purpose, so it has no example.

## Fix

Give the user who runs the compiler read and search permission on the
directory and on every module directory below it. Then run the command again.
