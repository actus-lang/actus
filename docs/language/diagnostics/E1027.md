# E1027: initializer does not match the declared type

A binding with a declared type must be initialized with a value of that type.
Actus converts nothing implicitly, so `Bool` does not become `Int`. The
message names the binding and both types. The error points at the
declaration. A `const` is checked the same way: its value must have the
declared type, so `const FLAG: Bool = 1;` is rejected.

## Example

```actus fails=E1027
verb main() {
    erg n: Int = true;
}
```

```actus fails=E1027
const FLAG: Bool = 1;

verb main() {
}
```

```actus fails=E1027
const SCALE: f32 = 1;

verb main() {
}
```

## Fix

Initialize the binding with a value of its type, or declare the type that the
value has.

```actus compiles
verb main() {
    erg n: Int = 1;
}
```

```actus compiles
const FLAG: Bool = true;
const SCALE: f32 = 1.5;

verb main() {
}
```
