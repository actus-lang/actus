# E1038: receiver of the wrong type

A method is called on a value whose type must be the type of its `self`
parameter. ADR-0029 keeps the receiver's type and role exactly as the verb
declares them. Two structs with the same fields are still different types. The
message names the method and both types, and the error points at the call.

## Example

```actus fails=E1038
struct Counter {
    n: Int,
}

struct Other {
    n: Int,
}

verb double(abs self: Counter) -> Int {
    return 2;
}

verb main() {
    erg o: Other = Other { n: 1, };
    abs view = ref o;
    print(view.double());
}
```

## Fix

Call the method on a value of the right type.

```actus compiles
struct Counter {
    n: Int,
}

struct Other {
    n: Int,
}

verb double(abs self: Counter) -> Int {
    return 2;
}

verb main() {
    erg c: Counter = Counter { n: 1, };
    abs view = ref c;
    print(view.double());
}
```
