# E1101: module has no canonical facade

An `import` names a module that the compiler cannot find on disk. A module is
either one file, `src/shapes.act`, or a directory with a canonical facade, a
file with the same name as the directory: `src/shapes/shapes.act`
(ADR-0018). The same error is reported for a subdirectory of a module that has
no facade of its own, and for a `std` module that does not exist. The message
names the facade file that the compiler expected.

## Example

```actus fails=E1101
import shapes;

verb main() {
}
```

```actus fails=E1101
import shapes;

verb main() {
}
```

```actus file=src/shapes/shapes.act
open circle;
```

```actus file=src/shapes/circle.act
open verb area() -> Int {
    return 1;
}
```

```actus file=src/shapes/helpers/rounding.act
verb round() -> Int {
    return 1;
}
```

## Fix

Create the facade. It lists the siblings that the module exports with
`open`.

```actus compiles
import shapes;

verb main() {
}
```

```actus file=src/shapes/shapes.act
open circle;
```

```actus file=src/shapes/circle.act
open verb area() -> Int {
    return 1;
}
```
