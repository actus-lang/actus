# E1022: verb name reserved for an intrinsic

Some names belong to built-in intrinsics: `allocate`, `append`,
`buffer_length`, `crc32`, `crc32_matches`, `validate_fixed_frame`, `drop`,
`size_of` and `align_of`. A program cannot declare a verb with one of these
names, because calls would be ambiguous. `print`, `eprint` and `copy` are not
reserved, and a verb of that name takes precedence over the intrinsic (see
ADR-0059). The error points at the declaration.

## Example

```actus fails=E1022
verb buffer_length(abs value: Int) -> Int {
    return copy(value: abs value);
}

verb main() {
}
```

## Fix

Choose another name.

```actus compiles
verb length_of(abs value: Int) -> Int {
    return copy(value: abs value);
}

verb main() {
}
```
