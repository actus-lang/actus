# E1147: `abs` struct field of a scalar type

A scalar has no view. An `abs` struct field is laid out as a pointer to its
source (ADR-0046 2.3), but a scalar `abs` parameter is passed by value, so a
holder built from such a parameter would carry a pointer into the dead frame of
the callee. Reading the field also fails LLVM verification. The declaration is
therefore rejected when the field type is `Int`, `Bool`, `Usize`, a fixed-width
integer (`u8` to `i64`) or a float. `String`, `Buffer`, structs, enums, packs
and arrays can be viewed and stay allowed. The message names the field, the
struct and the type. The error points at the field.

## Example

```actus fails=E1147
struct Count {
    abs held: Int,
}

verb main() {
}
```

## Fix

Declare a plain field, which copies the value.

```actus compiles
struct Count {
    held: Int,
}

verb main() {
}
```
