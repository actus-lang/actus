# E1851: source file has reached the size where it must be split

A source file has 600 or more code lines, the size at which strict mode
(`--strict`, ADR-0041) requires the file to be split. The code lines are the
lines that are neither blank nor a comment. `E1850` reports a file above 500
code lines and `E1852` one above 800; this code is the range between. The
message names the count, as in `source file has 600 code lines; split is
required at 600`.

## Example

The comment `# catalog: repeat N` stands for N copies of the lines up to
`# catalog: end`, with `{n}` replaced by the copy's number. The example is 299
functions `step_001` to `step_299`, 2 code lines each, and `main`, which make
600 code lines.

```actus fails=E1851,strict
# catalog: repeat 299
verb step_{n}() {
}
# catalog: end
verb main() {
}
```

## Fix

Split the file by responsibility: move the declarations that belong together
into a module of their own, so that each file stays below the limit.

```actus compiles strict file=src/main.act
import steps;

verb main() {
}
```

```actus file=src/steps/steps.act
open first;
```

```actus file=src/steps/first.act
open verb first_step() {
}
```
