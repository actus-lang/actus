# E1077: arena reference escapes its arena

A value that `place` puts in an arena is only valid while the arena lives
(ADR-0030). A reference that is derived from the arena may not be stored in a
binding that outlives the arena's scope, and it may not be returned from the
verb, because the arena is released when its scope ends. The message names the
binding. The error points at the return or at the assignment.

## Example

```actus fails=E1077
struct Node {
    value: Int,
}

verb make() -> Node {
    erg arena: Arena[64] = Arena[64]();
    erg node: Node = arena.place(value: Node { value: 1, });
    return node;
}

verb main() {
}
```

```actus fails=E1077
struct Node {
    value: Int,
}

verb main() {
    erg outer: Node = Node { value: 0, };
    {
        erg arena: Arena[64] = Arena[64]();
        erg inner = arena.place(value: Node { value: 1, });
        outer = inner;
    }
}
```

## Fix

Return or keep a plain value instead of the reference, for example the field
that the caller needs. Move the arena to the scope that needs the data when
the data must live longer.

```actus compiles
struct Node {
    value: Int,
}

verb make() -> Int {
    erg arena: Arena[64] = Arena[64]();
    erg node: Node = arena.place(value: Node { value: 1, });
    return node.value;
}

verb main() {
}
```

```actus compiles
struct Node {
    value: Int,
}

verb main() {
    erg total: Int = 0;
    {
        erg arena: Arena[64] = Arena[64]();
        erg inner = arena.place(value: Node { value: 1, });
        total = inner.value;
    }
}
```
