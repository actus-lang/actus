# E1127: realtime code uses floating point

A verb marked `meta realtime` may not use floating-point literals, types or
operations (ADR-0094). The error points at the first use. Use integers, for
example fixed-point values that you scale yourself.

## Example

```actus fails=E1127
meta realtime
verb scale() -> Int {
    erg ratio = 0.5;
    return 1;
}

verb main() {
}
```

## Fix

Work in integers.

```actus compiles
meta realtime
verb scale() -> Int {
    erg half: Int = 1;
    return half * 2;
}

verb main() {
}
```
