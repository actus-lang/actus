# E0027: invalid float type

Floating-point types are `f32` and `f64`. The same names are the suffixes of
float literals, such as `1.5f32`. The lexer reports this error for any other
suffix, such as `f16` or `f128`. Before ADR-0123 this error was reported as
`E0006`, which is also a parser code.

## Example

```actus fails=E0027
verb main() {
    erg ratio = 1.5f16;
}
```

## Fix

Use `f32` or `f64`.

```actus compiles
verb main() {
    erg ratio = 1.5f32;
}
```
