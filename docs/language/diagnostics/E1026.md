# E1026: returned value has the wrong type

The value of a `return` statement must have the type that the verb declares
after `->`. The message names both types. The error points at the returned
expression.

## Example

```actus fails=E1026
verb size() -> Int {
    return true;
}

verb main() {
}
```

## Fix

Return a value of the declared type, or change the declared return type.

```actus compiles
verb size() -> Int {
    return 1;
}

verb main() {
}
```
