# E1089: dynamic parameter must be abs

A parameter of the form `dynamic Role` receives any value that performs the
role, through a pointer that the callee does not own (ADR-0014). The callee
therefore may only look at it, and the parameter must use the `abs` role.
`erg`, `dat` and `ins` would let the callee own, consume or change a value
whose type it does not know. The message names the parameter. The error
points at the parameter.

## Example

```actus fails=E1089
struct Cursor {
    position: Int,
}

role Reader {
    verb read(abs self: Cursor) -> Int;
}

verb pull(erg source: dynamic Reader) -> Int {
    return 0;
}

verb main() {
}
```

## Fix

Declare the parameter `abs`.

```actus compiles
struct Cursor {
    position: Int,
}

role Reader {
    verb read(abs self: Cursor) -> Int;
}

verb pull(abs source: dynamic Reader) -> Int {
    return 0;
}

verb main() {
}
```
