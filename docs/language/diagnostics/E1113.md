# E1113: configuration module has an import

The module `config` is the place for the compile-time values of a package. Its
files may declare constants and the types that describe them. They may not
contain an `import`, so the configuration cannot depend on code that runs at
run time (ADR-0054). The error points at the import. The same rule applies to
every module below `config`.

The message names the configuration module. It also names the file that holds
the import, not the module that the import wanted.

## Example

```actus fails=E1113 file=src/main.act
import config;

verb main() {
    erg limit = config::LIMIT;
}
```

```actus file=src/config/config.act
import other;
open values;
```

```actus file=src/config/values.act
open const LIMIT: u8 = 30u8;
```

```actus file=src/other/other.act
open items;
```

```actus file=src/other/items.act
open const ITEM: u8 = 1u8;
```

## Fix

Remove the import. Move the value that the configuration needs into the
configuration module itself, or let the other module import `config`.

```actus compiles file=src/main.act
import config;

verb main() {
    erg limit = config::LIMIT;
}
```

```actus file=src/config/config.act
open values;
```

```actus file=src/config/values.act
open const LIMIT: u8 = 30u8;
```
