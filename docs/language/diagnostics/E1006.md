# E1006: use of a dropped binding

`drop` releases a resource at once. ADR-0027 makes the release happen exactly
once, so the binding is dead afterwards and any later read, borrow or move is
rejected. The error points at the later use.

## Example

```actus fails=E1006
verb main() {
    erg data: Buffer = Buffer[4];
    drop(data);
    print(buffer_length(buffer: abs data));
}
```

## Fix

Use the value before it is dropped. Most owners need no `drop` at all, because
the compiler releases them at the end of their scope.

```actus compiles
verb main() {
    erg data: Buffer = Buffer[4];
    print(buffer_length(buffer: abs data));
    drop(data);
}
```
