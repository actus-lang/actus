# E0014: malformed verb contract

A documentation block that starts with the line `contract:` is a structured
contract, and ADR-0065 fixes its shape. It is a list of sections named
`purpose`, `inputs`, `outputs`, `ownership`, `invariants`, `errors`,
`side_effects` and `abi`, each written as its name and a colon on one line,
with the text below it. The parser rejects an unknown or repeated section
name, an empty section name, text before the first section, and a contract
without any section. A documentation block without the `contract:` line is
never checked this way.

## Example

```actus fails=E0014
"""
contract:
speed:
    Fast.
"""
verb main() {
}
```

## Fix

Use the section names from the list, once each.

```actus compiles
"""
contract:
purpose:
    Starts the program.
"""
verb main() {
}
```
