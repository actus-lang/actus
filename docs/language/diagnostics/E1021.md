# E1021: invalid argument for a built-in intrinsic

Built-in intrinsics such as `buffer_length`, `crc32` and `copy` check their
arguments more strictly than ordinary verbs. The buffer must be a readable
`Buffer`, ranges and sizes must be integers, and `copy` accepts only a scalar
(`Int`, `Bool`, an integer or a float type; ADR-0059) or a struct, an enum or a
pack declared `meta copy`, or an `Array` whose element type is itself a copy
type (ADR-0124). The message names the intrinsic and the parameter. The error points at the argument.

## Example

```actus fails=E1021
verb main() {
    erg n: Int = 4;
    print(buffer_length(buffer: abs n));
}
```

```actus fails=E1021
verb main() {
    erg data: Buffer = Buffer[4];
    erg copied = copy(value: abs data);
}
```

```actus fails=E1021
struct Plain {
    value: Int,
}

verb main() {
    erg plain = Plain { value: 1, };
    erg copied = copy(value: abs plain);
}
```

```actus fails=E1021
verb main() {
    erg slots: Array[Buffer, 2] = Array[Buffer, 2]();
    erg copied: Array[Buffer, 2] = copy(value: abs slots);
}
```

## Fix

Pass a value of the type that the parameter needs. A buffer cannot be
copied, so when a second owner is needed, move the first one. A struct, an
enum or a pack of plain data can declare `meta copy` to be copied.

```actus compiles
verb main() {
    erg data: Buffer = Buffer[4];
    print(buffer_length(buffer: abs data));
}
```

```actus compiles
verb main() {
    erg data: Buffer = Buffer[4];
    erg moved = data;
}
```

```actus compiles
meta copy
struct Plain {
    value: Int,
}

verb main() {
    erg plain = Plain { value: 1, };
    erg copied = copy(value: abs plain);
}
```

```actus compiles
verb main() {
    erg values: Array[Int, 3] = Array[Int, 3]();
    erg copied: Array[Int, 3] = copy(value: abs values);
}
```
