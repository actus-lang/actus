# E1021: invalid argument for a built-in intrinsic

Built-in intrinsics such as `buffer_length`, `crc32` and `copy` check their
arguments more strictly than ordinary verbs. The buffer must be a readable
`Buffer`, ranges and sizes must be integers, and `copy` accepts only scalar
values of type `Int`, `Bool` or an integer type (ADR-0059). The message names
the intrinsic and the parameter. The error points at the argument.

## Example

```actus fails=E1021
verb main() {
    erg n: Int = 4;
    print(buffer_length(buffer: abs n));
}
```

```actus fails=E1021
verb main() {
    erg data: Buffer = Buffer[4];
    erg copied = copy(value: abs data);
}
```

## Fix

Pass a value of the type that the parameter needs. A buffer cannot be
copied, so when a second owner is needed, move the first one.

```actus compiles
verb main() {
    erg data: Buffer = Buffer[4];
    print(buffer_length(buffer: abs data));
}
```

```actus compiles
verb main() {
    erg data: Buffer = Buffer[4];
    erg moved = data;
}
```
