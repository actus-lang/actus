# E1079: arena dropped while a reference is live

A reference into an arena is only valid while the arena exists, so the arena
may not be dropped (or moved) while a live `abs` or `ins` binding refers to
one of its values (ADR-0030). The message names the arena and the reference.
The error points at the `drop`. A view lives until the end of the block that
holds it, but the check also counts a view in a block that has already ended.

## Example

```actus fails=E1079
struct Node {
    value: Int,
}

verb main() {
    erg arena: Arena[64] = Arena[64]();
    erg node = arena.place(value: Node { value: 1, });
    abs view = ref node;
    drop(arena);
    print(view.value);
}
```

## Fix

Finish with the values first, and create no view of them that is still live
when the arena is dropped. An arena that is not dropped explicitly is released
when its scope ends.

```actus compiles
struct Node {
    value: Int,
}

verb main() {
    erg arena: Arena[64] = Arena[64]();
    erg node = arena.place(value: Node { value: 1, });
    print(node.value);
    drop(arena);
}
```
