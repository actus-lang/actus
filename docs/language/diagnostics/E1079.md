# E1079: arena moved or dropped while a reference is live

A reference into an arena is only valid while the arena exists, so the arena
may not be moved, dropped, or overwritten while a live `abs` or `ins` binding
refers to one of its values (ADR-0030). Every way of giving the arena up counts:
`drop(arena)`, a `dat` argument, `erg other = arena`, an assignment from or to
the arena, and a struct field that takes it, whether the field is `erg` or has
no role. The message names the arena and
the reference. The error points at the move or the `drop`.

A view lives until the end of the block that holds it, as for E1011, so a view
in a block that has already ended does not block the release. A value that was
placed in the arena is not a view, so it does not block the release either, but
it may not be read once the arena is gone. That read is the same error, and it
points at the read.

## Example

```actus fails=E1079
struct Node {
    value: Int,
}

verb main() {
    erg arena: Arena[64] = Arena[64]();
    erg node = arena.place(value: Node { value: 1, });
    abs view = ref node;
    drop(arena);
    print(view.value);
}
```

```actus fails=E1079
struct Node {
    value: Int,
}

verb take(dat arena: Arena[64]) {
}

verb main() {
    erg arena: Arena[64] = Arena[64]();
    erg node = arena.place(value: Node { value: 1, });
    abs view = ref node;
    take(arena: arena);
    print(view.value);
}
```

A struct field without a role moves the arena the same way:

```actus fails=E1079
struct Node {
    value: Int,
}

struct Holder {
    held: Arena[64],
}

verb main() {
    erg arena: Arena[64] = Arena[64]();
    erg node = arena.place(value: Node { value: 1, });
    abs view = ref node;
    erg holder = Holder { held: arena, };
    print(view.value);
}
```

A placed value is only readable while an owner of its arena is still in scope.
Here the new owner ends with its block, so the read of `node` fails:

```actus fails=E1079
struct Node {
    value: Int,
}

verb main() {
    erg arena: Arena[64] = Arena[64]();
    erg node = arena.place(value: Node { value: 1, });
    {
        erg other = arena;
    }
    print(node.value);
}
```

## Fix

Finish with the values first, and create no view of them that is still live
when the arena is moved or dropped. Keep a view in its own block so that it ends
before the arena is released. An arena that is not dropped explicitly is
released when its scope ends.

```actus compiles
struct Node {
    value: Int,
}

verb take(dat arena: Arena[64]) {
}

verb main() {
    erg arena: Arena[64] = Arena[64]();
    erg node = arena.place(value: Node { value: 1, });
    {
        abs view = ref node;
        print(view.value);
    }
    take(arena: arena);
}
```

```actus compiles
struct Node {
    value: Int,
}

verb main() {
    erg arena: Arena[64] = Arena[64]();
    erg node = arena.place(value: Node { value: 1, });
    print(node.value);
    drop(arena);
}
```
