# E1017: positional call is ambiguous

A positional call is allowed only when the arguments cannot be confused. If a
verb has two parameters with the same role and the same type, swapping the
arguments would still compile and silently change the result. The compiler
rejects every positional call to such a verb, whatever the arguments are. The
error points at the call.

## Example

```actus fails=E1017
verb scale(abs value: Int, abs factor: Int) -> Int {
    return value * factor;
}

verb main() {
    erg a: Int = 2;
    erg b: Int = 3;
    print(scale(a, b));
}
```

## Fix

Name the arguments, which also shows their roles.

```actus compiles
verb scale(abs value: Int, abs factor: Int) -> Int {
    return value * factor;
}

verb main() {
    erg a: Int = 2;
    erg b: Int = 3;
    print(scale(value: abs a, factor: abs b));
}
```
