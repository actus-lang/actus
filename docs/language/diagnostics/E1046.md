# E1046: pattern can never match

Branches of a `case` are tried from top to bottom. A branch that follows an
unguarded `_` branch is never reached, because `_` already matches every
value. The compiler rejects the dead branch. The message shows the pattern,
and the error points at it.

## Example

```actus fails=E1046
enum Color {
    Red,
    Green,
}

verb name(abs c: Color) -> Int {
    return case c {
        _ => 0,
        Color.Red => 1,
    };
}

verb main() {
}
```

## Fix

Put the `_` branch last.

```actus compiles
enum Color {
    Red,
    Green,
}

verb name(abs c: Color) -> Int {
    return case c {
        Color.Red => 1,
        _ => 0,
    };
}

verb main() {
}
```
