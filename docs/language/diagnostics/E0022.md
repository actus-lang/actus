# E0022: unsupported representation

`meta repr(...)` selects the memory layout of a type. ADR-0097 allows a
closed set of bare names: `C`, `packed`, `transparent` and `align(N)`, where
`N` is a positive `u32` literal, as in `align(8u32)`. Any other name, such as a
string, is rejected, and so is an alignment that is not a positive `u32`
literal. The error points at the offending name or value.

## Example

```actus fails=E0022
meta repr(wide)
struct Point {
    x: Int,
}

verb main() {
}
```

## Fix

Use one of the names, without quotes.

```actus compiles
meta repr(C)
struct Point {
    x: Int,
}

verb main() {
}
```
