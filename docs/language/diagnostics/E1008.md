# E1008: drop of a borrowed parameter

`drop` is for owners. An `abs` view and an `ins` loan are non-owning, and
ADR-0027 says they never receive an owned drop. The caller still owns the
value and releases it. The error points at the `drop` statement.

## Example

```actus fails=E1008
verb eat(ins data: Buffer) {
    drop(data);
}

verb main() {
}
```

## Fix

If the callee should end the life of the value, declare the parameter `dat`.
The caller then gives up ownership, and the callee may drop it.

```actus compiles
verb eat(dat data: Buffer) {
    drop(data);
}

verb main() {
}
```
