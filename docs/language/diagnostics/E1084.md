# E1084: array index is not an integer

An index selects a slot by number, so it must have an integer type (ADR-0042).
`Int`, `Usize` and the fixed-width integers are accepted. A `Bool`, a struct
or a string is rejected. The message names the type that was found. The error
points at the index expression.

## Example

```actus fails=E1084
verb main() {
    erg values: Array[Int, 4] = Array[Int, 4]();
    erg flag: Bool = true;
    erg x = values[flag];
}
```

## Fix

Index with an integer. A `Bool` cannot be cast to one, because `as` converts
only between integer types, so choose the slot with an integer value.

```actus compiles
verb main() {
    erg values: Array[Int, 4] = Array[Int, 4]();
    erg slot: Int = 1;
    erg x = values[slot];
}
```
