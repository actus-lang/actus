# E1043: enum variant value has the wrong type

The value for a payload field must have the field's declared type. Actus has
no implicit conversion. The message names the variant, the field, and both
types. A positional field is named by its position, so the first field is
`0`. The error points at the value.

## Example

```actus fails=E1043
enum Shape {
    Circle { radius: u32, },
}

verb main() {
    erg s: Shape = Shape.Circle(radius: true);
}
```

## Fix

Give the field a value of its type.

```actus compiles
enum Shape {
    Circle { radius: u32, },
}

verb main() {
    erg s: Shape = Shape.Circle(radius: 1u32);
}
```
