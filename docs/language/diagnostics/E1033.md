# E1033: field value has the wrong type

The value given to a struct field, in a literal or in an assignment, must have
the type that the field declares. The message names the field, the struct and
both types. The error points at the value.

## Example

```actus fails=E1033
struct Point {
    x: Int,
}

verb main() {
    erg p: Point = Point { x: true, };
}
```

## Fix

Give the field a value of its type, or change the type of the field.

```actus compiles
struct Point {
    x: Int,
}

verb main() {
    erg p: Point = Point { x: 1, };
}
```
