# E0023: invalid stack limit

`meta stack_limit(bytes: N)` sets the stack budget of a verb. ADR-0103 fixes
the form: one parameter named `bytes`, whose value is a positive `u32` literal
with the suffix, such as `2048u32`. The parser rejects a value of zero, a value
without the suffix, another parameter name, and a second parameter. The message
gives the reason.

## Example

```actus fails=E0023
meta stack_limit(bytes: 0u32)
verb main() {
}
```

## Fix

Write a positive `u32` literal.

```actus compiles llvm
meta stack_limit(bytes: 2048u32)
verb main() {
}
```
