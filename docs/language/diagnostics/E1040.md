# E1040: unknown enum variant

An enum has a closed set of variants. A constructor such as `Color.Green` or a
pattern in a `case` names a variant that the enum does not declare. The
message names the variant and the enum, and the error points at the name.

## Example

```actus fails=E1040
enum Color {
    Red,
    Blue,
}

verb main() {
    erg c: Color = Color.Green;
}
```

## Fix

Use a variant that the enum declares, or add the variant to the enum.

```actus compiles
enum Color {
    Red,
    Blue,
}

verb main() {
    erg c: Color = Color.Blue;
}
```
