# E0002: unterminated string literal

A string literal starts and ends with a double quote on the same line. The
lexer reports this error when it reaches the end of the line or of the file
before it finds the closing quote. The error points at the opening quote.

## Example

```actus fails=E0002
verb main() {
    print(string: "hello);
}
```

## Fix

Add the closing quote.

```actus compiles
verb main() {
    print(string: "hello");
}
```
