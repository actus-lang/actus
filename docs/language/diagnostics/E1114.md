# E1114: configuration module has a runtime declaration

A configuration module holds values that are fixed at compile time. A `verb`,
an external verb, a `role` or a `perform` is code that runs, so it does not
belong there (ADR-0054). Constants, structs, enums, packs and `open` lines are
allowed. The error points at the declaration, and the message names its kind.

## Example

```actus fails=E1114 file=src/main.act
import config;

verb main() {
    erg limit = config::LIMIT;
}
```

```actus file=src/config/config.act
open values;
```

```actus file=src/config/values.act
open const LIMIT: u8 = 30u8;

open verb runtime_state() -> Int {
    return 1;
}
```

## Fix

Keep only compile-time declarations in `config`. Put the verb in an ordinary
module.

```actus compiles file=src/main.act
import config;

verb main() {
    erg limit = config::LIMIT;
}
```

```actus file=src/config/config.act
open values;
```

```actus file=src/config/values.act
open const LIMIT: u8 = 30u8;
```
