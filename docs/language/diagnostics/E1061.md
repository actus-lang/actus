# E1061: branches leave a binding in different states

After a `case` or an `if` the compiler must know what happened to each
binding, so every branch has to leave it in the same ownership and access
state (ADR-0016). A branch that drops or moves an owner while another branch
keeps it leaves the owner live on one path and gone on the other, and the
cleanup after the join could not be decided. The message names the binding and
the two states, written as ownership and access, and says `case branch`
even for an `if`. The error points at the `case` or `if`.

## Example

```actus fails=E1061
enum Mode {
    Fast,
    Slow,
}

verb main() {
    erg data: Buffer = Buffer[4];
    erg mode: Mode = Mode.Fast;
    case abs mode {
        Mode.Fast => {
            drop(data);
        },
        Mode.Slow => {
        },
    };
}
```

```actus fails=E1061
verb main() {
    erg data: Buffer = Buffer[4];
    erg flag: Bool = true;
    if flag {
        drop(data);
    }
}
```

The paths that leave a loop are joined the same way: every `break`, and for a
`for` loop over a range or an array also its normal exit, which keeps the
value. A `for` loop that moves a value and then breaks leaves it moved on one
path and live on the other, so the error points at the loop:

```actus fails=E1061
verb main() {
    erg data: Buffer = Buffer[4];
    for erg index in 0..3 {
        drop(data);
        break;
    }
}
```

## Fix

Treat the binding the same way in every branch, or move the drop or the move
after the join.

```actus compiles
enum Mode {
    Fast,
    Slow,
}

verb main() {
    erg data: Buffer = Buffer[4];
    erg mode: Mode = Mode.Fast;
    case abs mode {
        Mode.Fast => {
            drop(data);
        },
        Mode.Slow => {
            drop(data);
        },
    };
}
```

```actus compiles
verb main() {
    erg data: Buffer = Buffer[4];
    erg flag: Bool = true;
    if flag {
        print(flag);
    }
    drop(data);
}
```
