# E1804: runtime profile is not supported

The `runtime` key of `[build]` selects the runtime profile of the program:
`core`, `std` or `freestanding` (ADR-0041). Any other value is rejected before
the sources are read. The report names `Actus.toml` and the line and column of
the value, and says which values exist, as in ``unknown variant `portable`,
expected one of `core`, `std`, `freestanding` ``. The code is the same with and
without `--strict`.

## Example

```toml fails=E1804 file=Actus.toml
[package]
name = "app"
version = "0.1.0"

[build]
runtime = "portable"
```

```actus file=src/main.act
verb main() {
}
```

## Fix

Use one of the profiles that exist.

```toml compiles file=Actus.toml
[package]
name = "app"
version = "0.1.0"

[build]
runtime = "core"
```

```actus file=src/main.act
verb main() {
}
```
