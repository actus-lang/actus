# E0010: conflicting target platforms

One declaration can carry only one `meta target` selector. When two
attributes in front of the same declaration name different selectors, no
platform could satisfy both, and ADR-0015 makes contradictory metadata a
compile-time error. The message names both selectors. `posix` and `unix` are
different selectors, even though they overlap on most hosts.

## Example

```actus fails=E0010
meta target("unix")
meta target("windows")
verb main() {
}
```

## Fix

Keep one selector. To have a version for each platform, write two
declarations, each with its own selector.

```actus compiles
meta target("unix")
verb main() {
}
```
