# E1009: drop of a binding that is borrowed

While an `abs` view of an owner is live, the owner is frozen. ADR-0027 says an
owner cannot be dropped while it is frozen by a view, because the view would
point at a released resource. The view lives until the end of the block that
holds it, whether or not it is used again. The error points at the `drop`.

## Example

```actus fails=E1009
verb main() {
    erg data: Buffer = Buffer[4];
    abs view = ref data;
    print(buffer_length(buffer: abs view));
    drop(data);
}
```

An `abs` struct field is a view too. The source stays frozen until the end of
the block that builds the struct:

```actus fails=E1009
struct Header {
    abs bytes: Buffer,
}

verb main() {
    erg data: Buffer = Buffer[4];
    erg header = Header { bytes: data, };
    drop(data);
}
```

## Fix

End the view first by putting it in an inner block, then drop the owner.

```actus compiles
verb main() {
    erg data: Buffer = Buffer[4];
    {
        abs view = ref data;
        print(buffer_length(buffer: abs view));
    }
    drop(data);
}
```
