# E1045: case does not cover every value

A `case` expression must handle every possible value of its subject (ADR-0013).
For an enum, each variant needs a branch, or a `_` branch must catch the rest.
For an integer subject, a `_` branch is required. A branch with a guard does
not count, because the guard may fail. The message lists the missing variants.
For an integer subject it shows `_`. The error points at the `case`.

## Example

```actus fails=E1045
enum Color {
    Red,
    Green,
    Blue,
}

verb name(abs c: Color) -> Int {
    return case c {
        Color.Red => 1,
        Color.Green => 2,
    };
}

verb main() {
}
```

## Fix

Add a branch for each missing variant, or a `_` branch.

```actus compiles
enum Color {
    Red,
    Green,
    Blue,
}

verb name(abs c: Color) -> Int {
    return case c {
        Color.Red => 1,
        Color.Green => 2,
        Color.Blue => 3,
    };
}

verb main() {
}
```
