# E0006: unknown metadata attribute

A `meta` line names one attribute from a closed list: `test`, `target`,
`fault`, `limitless`, `must_use`, `effect`, `deterministic`, `realtime`,
`bounded`, `stack_limit`, `capability`, `repr`, `volatile` and `zero_on_drop`.
Any other name is rejected, as is a `meta fault` with a fault name that the
test runner does not know. ADR-0089 requires every attribute to be registered
and rejects unknown names at compile time, so a misspelled attribute never
turns into a silent comment.

## Example

```actus fails=E0006
meta inline
verb answer() -> Int {
    return 42;
}

verb main() {
}
```

## Fix

Use a name from the list, spelled as shown. Attributes that Actus does not
have, such as `inline`, are removed.

```actus compiles
meta must_use("the answer is needed")
verb answer() -> Int {
    return 42;
}

verb main() {
    erg value = answer();
}
```
