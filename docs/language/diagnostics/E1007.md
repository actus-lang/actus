# E1007: binding dropped twice

A resource is released exactly once (ADR-0027). The compiler rejects a `drop`
of a binding that was already dropped. It rejects the same `drop` of a binding
that was moved or partly moved, because the new owner is responsible for the
release. The message always reads "dropped twice", also for a moved binding.
The error points at the second `drop`.

## Example

```actus fails=E1007
verb main() {
    erg data: Buffer = Buffer[4];
    drop(data);
    drop(data);
}
```

## Fix

Drop the binding once. Without an explicit `drop`, the compiler releases it
when its scope ends.

```actus compiles
verb main() {
    erg data: Buffer = Buffer[4];
    drop(data);
}
```
