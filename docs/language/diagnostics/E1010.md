# E1010: value cannot be moved out of a view or transferred with dat

A `dat` argument moves ownership into the callee (ADR-0016). Only an owner can
be moved, so the argument must be an `erg` binding, a `dat` binding or an
`erg` field of such a binding. An `abs` binding is a view of someone else's
value. A constructor such as `Buffer[4]` has no binding to hand over. An `ins`
binding is a loan and is rejected with E1082. The message
names the binding or field, or says `expression` when there is none. The error
points at the argument.

The same rule covers a field or an element read by value through an `abs` view
(ADR-0124). A struct, enum, pack, array or buffer taken from `view.field`,
`view.a.b` or `view.items[0]` and returned, bound to an `erg`, assigned,
passed to a `dat` parameter, or stored in a struct literal field or an enum
payload cannot be moved, because a view owns nothing, and it is not copied,
because nothing writes a copy, so it would be shared silently. The message names
the path. When the type is a copy type it says to write
`copy(value: abs view.field)`; otherwise it says the value cannot leave the
view: borrow it with `abs`, or take ownership of the owner. Through an `ins`
loan the same read is E1082. A scalar read is not affected, nor is taking a view
of the field (`abs h = ref view.field`, an `abs` argument, `-> abs`).

## Example

```actus fails=E1010
verb eat(dat data: Buffer) {
    drop(data);
}

verb pass(abs data: Buffer) {
    eat(data: dat data);
}

verb main() {
}
```

```actus fails=E1010
verb eat(dat data: Buffer) {
    drop(data);
}

verb main() {
    eat(data: dat Buffer[4]);
}
```

```actus fails=E1010
meta copy
struct Header {
    kind: u8,
    payload_len: u16,
}

struct Parser {
    erg header: Header,
}

verb get(abs parser: Parser) -> Header {
    return parser.header;
}

verb main() {
}
```

```actus fails=E1010
struct Event {
    erg name: Buffer,
}

verb take(dat name: Buffer) {
    drop(name);
}

verb relay(abs event: Event) {
    take(name: dat event.name);
}

verb main() {
}
```

## Fix

For a view field that is a copy type, write the copy. Otherwise borrow the
field, or let the caller own the value. Declare the forwarding parameter `dat`, or bind
the new value to an `erg` first and move that binding.

```actus compiles
verb eat(dat data: Buffer) {
    drop(data);
}

verb pass(dat data: Buffer) {
    eat(data: dat data);
}

verb main() {
}
```

```actus compiles
verb eat(dat data: Buffer) {
    drop(data);
}

verb main() {
    erg data: Buffer = Buffer[4];
    eat(data: dat data);
}
```

```actus compiles
meta copy
struct Header {
    kind: u8,
    payload_len: u16,
}

struct Parser {
    erg header: Header,
}

verb get(abs parser: Parser) -> Header {
    return copy(value: abs parser.header);
}

verb main() {
}
```

```actus compiles
meta copy
struct Header {
    kind: u8,
    payload_len: u16,
}

struct Parser {
    erg header: Header,
}

verb show(abs header: Header) -> u16 {
    return header.payload_len;
}

verb read(abs parser: Parser) -> u16 {
    return show(header: abs parser.header);
}

verb main() {
}
```
