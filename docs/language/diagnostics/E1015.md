# E1015: wrong number of arguments

A call must pass one argument for every parameter of the verb, no more and no
fewer. The compiler checks the count before it looks at names, roles or
types. The error points at the call. The same code is reported for a built-in
intrinsic that is called with the wrong number of arguments.

## Example

```actus fails=E1015
verb scale(abs value: Int, abs factor: Int) -> Int {
    return value * factor;
}

verb main() {
    erg a: Int = 2;
    print(scale(value: abs a));
}
```

## Fix

Pass an argument for every parameter, or change the verb's declaration if it
needs fewer.

```actus compiles
verb scale(abs value: Int, abs factor: Int) -> Int {
    return value * factor;
}

verb main() {
    erg a: Int = 2;
    print(scale(value: abs a, factor: abs a));
}
```
