# E0012: unsupported limitless scope

`meta limitless` takes one string, the scope of the exception. ADR-0048 allows
exactly two scopes: `"verb"` for the next verb and `"file"` for the whole
file. Any other string is rejected, so a scope that the conformance tools do
not understand is never accepted silently.

## Example

```actus fails=E0012
meta limitless("module")
verb main() {
}
```

## Fix

Use `"verb"` or `"file"`.

```actus compiles
meta limitless("verb")
verb main() {
}
```
