# E1862: dynamic call without a closed set of implementations

A `meta stack_limit` verb needs a bound for every call it makes (ADR-0103).
A call through a `dynamic` role value can reach any implementation of the
method, so the bound is only known when the program has its implementations
and they are all visible. The compiler reports this error when it finds no
`perform` that defines the called method. The error points at the call and
names the method.

## Example

```actus fails=E1862
role Writer {
    verb write(abs self: Int) -> Int;
}

meta stack_limit(bytes: 256u32)
verb send(abs writer: dynamic Writer) -> Int {
    return writer.write();
}

verb main() {
}
```

## Fix

Implement the role with a `perform` block, so the set of implementations is
known to the compiler.

```actus compiles
struct File {
    value: Int,
}

role Writer {
    verb write(abs self: File) -> Int;
}

perform Writer for File {
    verb write(abs self: File) -> Int {
        return self.value;
    }
}

meta stack_limit(bytes: 256u32)
verb send(abs writer: dynamic Writer) -> Int {
    return writer.write();
}

verb main() {
}
```
