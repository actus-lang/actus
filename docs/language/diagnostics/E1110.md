# E1110: two modules declare one name

A program is compiled as one unit. Inside it, a declaration name is unique,
even when the two declarations sit in different modules and are used with
different qualifiers (ADR-0110). Two modules that export a verb, struct, enum
or constant with the same name but different content collide, and the
compiler rejects the program before it generates code. The message names the
symbol and both modules.

The rule also covers native declarations. Two `extern "C"` declarations of
one symbol are one declaration only when their ownership roles, types and
return types are identical. If they differ, the program would link one symbol
with two incompatible contracts. Two identical declarations are accepted.

## Example

```actus fails=E1110 file=src/main.act
import circle;
import square;

verb main() {
}
```

```actus file=src/circle/circle.act
open area;
```

```actus file=src/circle/area.act
open verb area() -> Int {
    return 1;
}
```

```actus file=src/square/square.act
open area;
```

```actus file=src/square/area.act
open verb area() -> Int {
    return 2;
}
```

```actus fails=E1110 file=src/main.act
import left;
import right;

verb main() {
}
```

```actus file=src/left/left.act
open bridge;
```

```actus file=src/left/bridge.act
open unsafe extern "C" verb shared_bridge(abs buffer: Buffer) -> Int;
```

```actus file=src/right/right.act
open bridge;
```

```actus file=src/right/bridge.act
open unsafe extern "C" verb shared_bridge(ins buffer: Buffer) -> Int;
```

## Fix

Rename one of the declarations, or make the two declarations identical. The
native declarations below have the same contract, so they are one symbol.

```actus compiles file=src/main.act
import left;
import right;

verb main() {
}
```

```actus file=src/left/left.act
open bridge;
```

```actus file=src/left/bridge.act
open unsafe extern "C" verb shared_bridge(abs buffer: Buffer) -> Int;
```

```actus file=src/right/right.act
open bridge;
```

```actus file=src/right/bridge.act
open unsafe extern "C" verb shared_bridge(abs buffer: Buffer) -> Int;
```
