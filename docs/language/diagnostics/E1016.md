# E1016: argument does not satisfy the parameter's role

Every parameter has a role, and the call site must state a matching role
(ADR-0020). The argument must also be able to play that role. An `ins`
parameter needs an exclusive loan of an active `erg` or `dat` owner. It cannot
be given a view, or a binding that is moved, frozen or suspended. An `erg`
parameter needs an active owner that is not frozen. An `erg` parameter also takes over a
buffer or an arena, so the caller cannot use it after the call (E1005). A method receiver is an
argument too, so `value.method()` follows the same rules. The error points at
the argument.

A `?` that cannot return early from where it stands is reported with the same
code (bug #130): a `?` in an argument of a verb, a method or an intrinsic such
as `print`, in a `case` guard, in the index of an assigned element, or in a
conditional, a loop or an `if` statement nested in the arm of a conditional
whose value an owner receives. The message names the place, and the error
points at the `?`. A `?` in the value of an `if` or `case` arm, on the right of
`&&` or `||`, in a condition, a `case` subject or a compound assignment is
accepted and returns early.

## Example

```actus fails=E1016
verb bump(ins value: Int) {
    value += 1;
}

verb main() {
    erg a: Int = 2;
    bump(value: abs a);
}
```

```actus fails=E1016
verb bump(ins value: Int) {
    value += 1;
}

verb relay(abs value: Int) {
    bump(value: ins value);
}

verb main() {
}
```

```actus fails=E1016
enum Fail {
    Bad,
}

verb load() -> Result[Int, Fail] {
    return Result[Int, Fail].Ok(4);
}

verb show() -> Result[Int, Fail] {
    print(load()?);
    return Result[Int, Fail].Ok(0);
}

verb main() {
}
```

## Fix

State the role that the parameter declares. When the argument is a view, the
forwarding verb must hold the same kind of access, so declare its parameter
`ins` too.

```actus compiles
verb bump(ins value: Int) {
    value += 1;
}

verb main() {
    erg a: Int = 2;
    bump(value: ins a);
}
```

```actus compiles
verb bump(ins value: Int) {
    value += 1;
}

verb relay(ins value: Int) {
    bump(value: ins value);
}

verb main() {
}
```

Bind a propagated value before passing it on:

```actus compiles
enum Fail {
    Bad,
}

verb load() -> Result[Int, Fail] {
    return Result[Int, Fail].Ok(4);
}

verb show() -> Result[Int, Fail] {
    erg value: Int = load()?;
    print(value);
    return Result[Int, Fail].Ok(0);
}

verb main() {
}
```
