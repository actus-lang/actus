# E1852: source file is above the hard size limit

A source file has more than 800 code lines, the hard limit that strict mode
(`--strict`, ADR-0041) never accepts. The code lines are the lines that carry
code; blank lines, `#` comments and `"""` documentation blocks do not count.
The message names the count, as in `source file has 802 code lines; hard limit
is 800`. A manifest that sets `source_limits = "limitless"` turns the size
checks off for its package.

## Example

The comment `# catalog: repeat N` stands for N copies of the lines up to
`# catalog: end`, with `{n}` replaced by the copy's number. The example is 400
functions `step_001` to `step_400`, 2 code lines each, and `main`, which make
802 code lines.

```actus fails=E1852,strict
# catalog: repeat 400
verb step_{n}() {
}
# catalog: end
verb main() {
}
```

## Fix

Split the file by responsibility: move the declarations that belong together
into a module of their own, so that each file stays below the limit.

When a large file is one cohesive unit that splitting would damage, mark it
with `meta limitless("file")` at its beginning (ADR-0048). The exception is
then visible in the source and in review, instead of hidden in a comment.

```actus compiles strict file=src/main.act
import steps;

"""Entry point of the example; it does nothing and returns no value."""
verb main() {
}
```

```actus file=src/steps/steps.act
"""Re-export the first step moved out of the large file."""
open first;
```

```actus file=src/steps/first.act
"""Do nothing, as the first step that was moved out of the large file."""
open verb first_step() {
}
```
