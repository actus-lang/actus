# E1856: comment that suppresses a source-size limit

The size limits of strict mode (`E1850` to `E1855`) cannot be switched off
from inside the source. A comment such as `# actus: allow(source-limit)` or
`# actus: ignore(source-limit)` that tries to do it is an error of its own. A
file or a function that is too large is accepted only through a checked
directive, `meta limitless("file")` or `meta limitless("verb")` (ADR-0048),
`source_limits = "limitless"` in the manifest of the package, or the reviewed
exception list of the repository (ADR-0041). The message is `source-local suppression of architectural limits is
forbidden`, and it points at the comment. Without `--strict` the comment is
only a comment.

## Example

```actus fails=E1856,strict
# actus: allow(source-limit)
verb main() {
}
```

## Fix

Remove the comment. If a file or a function is too large, split it. When it
is one cohesive unit that should stay whole, mark it with
`meta limitless("file")` or `meta limitless("verb")` (ADR-0048): unlike a
comment, the directive is part of the language and is checked.

```actus compiles strict
"""Entry point of the example; it does nothing and returns no value."""
verb main() {
}
```
