# E1800: configuration cannot be loaded

The manifest `Actus.toml`, its lockfile or its dependencies could not be turned
into a configuration, and no more specific code of the `E1800` range applies.
The compiler stops before it reads any source file (ADR-0041). The report names
the file and, when the file can say where, the line and column of the offending
key or value, as in `Actus.toml: error[E1800] at 1:9: cannot parse the
manifest: unclosed table, expected `]``. The code is the same with and without
`--strict`.

The range holds the cases that have a code of their own: `E1801` for the
package name, `E1804` and `E1805` for the runtime profile, `E1882` for the
linker.

## Example

A table header that is never closed:

```toml fails=E1800 file=Actus.toml
[package
name = "app"
version = "0.1.0"
```

```actus file=src/main.act
verb main() {
}
```

A `source_root` that is not a directory:

```toml fails=E1800 file=Actus.toml
[package]
name = "app"
version = "0.1.0"
source_root = "missing"
```

```actus file=src/main.act
verb main() {
}
```

## Fix

Correct the manifest at the place the report names.

```toml compiles file=Actus.toml
[package]
name = "app"
version = "0.1.0"
```

```actus file=src/main.act
verb main() {
}
```
