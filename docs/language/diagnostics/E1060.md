# E1060: role method has no explicit receiver

Every method of a role names its receiver as the first parameter, called
`self`, and the role of that parameter is part of the contract (ADR-0014).
The compiler rejects a method that has no parameters or whose first
parameter has another name. It also rejects a parameter of type `Self` that
is not the first one. The message names the method and the role. The error
points at the method or at the misplaced parameter.

## Example

```actus fails=E1060
struct Cursor {
    position: Int,
}

role Reader {
    verb read(abs cursor: Cursor) -> Int;
}

verb main() {
}
```

```actus fails=E1060
role Reader {
    verb read() -> Int;
}

verb main() {
}
```

## Fix

Make `self` the first parameter and give it the ownership role that the
method needs.

```actus compiles
struct Cursor {
    position: Int,
}

role Reader {
    verb read(abs self: Cursor) -> Int;
}

verb main() {
}
```
