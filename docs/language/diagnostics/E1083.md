# E1083: array capacity is not a positive constant

`Array[T, N]` holds exactly `N` elements in storage whose size is fixed when
the program is compiled (ADR-0042). `N` must be a positive integer literal,
a positive constant of type `Usize`, or a const generic parameter. Zero is
rejected because the array would have no slot, and a runtime binding is
rejected because its value is not known at compile time. The message names
the capacity that was written. The error points at the statement that holds
the type.

## Example

```actus fails=E1083
verb main() {
    erg values: Array[Int, 0] = Array[Int, 0]();
}
```

```actus fails=E1083
verb main() {
    erg n: Int = 4;
    erg values: Array[Int, n] = Array[Int, n]();
}
```

## Fix

Use a positive literal or a named constant for the capacity.

```actus compiles
verb main() {
    erg values: Array[Int, 4] = Array[Int, 4]();
}
```

```actus compiles
const SLOTS: Usize = 4;

verb main() {
    erg values: Array[Int, SLOTS] = Array[Int, SLOTS]();
}
```
