# E1118: constant depends on itself

The value of a constant is computed at compile time from literals and from
other constants. If constant `FIRST` needs `SECOND`, and `SECOND` needs
`FIRST`, no value can be computed. The compiler detects the cycle and reports
it at one constant of the cycle (ADR-0052, ADR-0062). A constant that names
itself is a cycle of length one.

## Example

```actus fails=E1118
const FIRST: u8 = SECOND;
const SECOND: u8 = FIRST;

verb main() {
}
```

## Fix

Break the cycle: give at least one constant of it a value that does not name
the others.

```actus compiles
const SECOND: u8 = 4u8;
const FIRST: u8 = SECOND;

verb main() {
}
```
