# E1109: declaration is not exported by its facade

Other modules see a declaration only when it leaves its module. Two things
must hold (ADR-0047). The declaration is marked `open`, and the facade of
its module opens the file that holds it with `open <file>;`. Every facade on
the way up to the importing unit must do the same. A name that is reached
without both steps is private, and the error points at the use. The `help` part
of the message tells which step is missing:

- the declaration is not marked `open`;
- the declaration is `open`, but the facade does not open its file;
- the facade opens the file only with `open unit <file>;`, which keeps the
  names inside the unit (ADR-0111).

The same error is reported when a public signature names a private type.

## Example

```actus fails=E1109 file=src/main.act
import shapes;

verb main() {
    erg size = shapes::area();
}
```

```actus file=src/shapes/shapes.act
open circle;
```

```actus file=src/shapes/circle.act
verb area() -> Int {
    return 1;
}
```

```actus fails=E1109 file=src/main.act
import shapes;

verb main() {
    erg size = shapes::area();
}
```

```actus file=src/shapes/shapes.act
open square;
```

```actus file=src/shapes/square.act
open verb side() -> Int {
    return 2;
}
```

```actus file=src/shapes/circle.act
open verb area() -> Int {
    return 1;
}
```

```actus fails=E1109 file=src/main.act
import shapes;

verb main() {
    erg size = shapes::area();
}
```

```actus file=src/shapes/shapes.act
open unit circle;
```

```actus file=src/shapes/circle.act
open verb area() -> Int {
    return 1;
}
```

## Fix

Mark the declaration `open`, and let the facade open its file with a plain
`open <file>;`.

```actus compiles file=src/main.act
import shapes;

verb main() {
    erg size = shapes::area();
}
```

```actus file=src/shapes/shapes.act
open circle;
```

```actus file=src/shapes/circle.act
open verb area() -> Int {
    return 1;
}
```
