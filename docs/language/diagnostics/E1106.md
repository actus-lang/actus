# E1106: duplicate declaration in a module

All `.act` files that sit directly in one module directory share one scope.
A name may be declared only once in it, so a verb, struct, enum, role or
constant that appears in two files of the module is an error (ADR-0018). The
error points at the second declaration, and the message names both files.
Across modules, ADR-0110 keeps declaration names unique within one program.

## Example

```actus fails=E1106 file=src/main.act
import shapes;

verb main() {
}
```

```actus file=src/shapes/shapes.act
open circle;
open square;
```

```actus file=src/shapes/circle.act
open verb area() -> Int {
    return 1;
}
```

```actus file=src/shapes/square.act
open verb area() -> Int {
    return 2;
}
```

## Fix

Give each declaration its own name. If the two declarations are the same
thing, keep one of them.

```actus compiles file=src/main.act
import shapes;

verb main() {
}
```

```actus file=src/shapes/shapes.act
open circle;
open square;
```

```actus file=src/shapes/circle.act
open verb circle_area() -> Int {
    return 1;
}
```

```actus file=src/shapes/square.act
open verb square_area() -> Int {
    return 2;
}
```
