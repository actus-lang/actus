# E1864: imported call without a stack claim

A `meta stack_limit` verb is only as bounded as the code it calls
(ADR-0103). A verb that comes from another module must publish its own
`meta stack_limit` claim, or the caller has no bound to add. The error points
at the call and names the imported verb, such as `math::add`. A call to an
`unsafe extern` function without a claim is E1861.

## Example

```actus fails=E1864 file=src/main.act
import math;

meta stack_limit(bytes: 256u32)
verb step() -> Int {
    return math::add();
}

verb main() {
}
```

```actus file=src/math/math.act
open add;
```

```actus file=src/math/add.act
open verb add() -> Int {
    return 1;
}
```

## Fix

Declare a stack limit on the imported verb.

```actus compiles llvm file=src/main.act
import math;

meta stack_limit(bytes: 256u32)
verb step() -> Int {
    return math::add();
}

verb main() {
}
```

```actus file=src/math/math.act
open add;
```

```actus file=src/math/add.act
meta stack_limit(bytes: 64u32)
open verb add() -> Int {
    return 1;
}
```
