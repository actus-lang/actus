# E1081: duplicate pack declaration

A pack name identifies one layout, and every use of the name refers to it.
Two `pack` declarations with the same name would give the name two layouts, so
the second one is rejected. The error points at the second declaration.

## Example

```actus fails=E1081
pack Flags {
    erg storage: u8;
    layout little;
    fields {
        erg enabled: u1 at 0;
        abs _reserved: u7 at 1 = 0;
    }
}

pack Flags {
    erg storage: u16;
    layout little;
    fields {
        erg enabled: u1 at 0;
        abs _reserved: u15 at 1 = 0;
    }
}

verb main() {
}
```

## Fix

Rename one of the packs.

```actus compiles
pack Flags {
    erg storage: u8;
    layout little;
    fields {
        erg enabled: u1 at 0;
        abs _reserved: u7 at 1 = 0;
    }
}

pack WideFlags {
    erg storage: u16;
    layout little;
    fields {
        erg enabled: u1 at 0;
        abs _reserved: u15 at 1 = 0;
    }
}

verb main() {
}
```
