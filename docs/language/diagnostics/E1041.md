# E1041: wrong number of values for an enum variant

A variant with a payload must be built with exactly one value for each
payload field, and a unit variant takes none. The same rule applies to the
sub-patterns of a `case` branch. The message gives the expected and the found
count. In a pattern it names the variant as `pattern.payload`. The error
points at the constructor or the pattern.

## Example

```actus fails=E1041
enum Shape {
    Circle(u32),
}

verb main() {
    erg s: Shape = Shape.Circle(1u32, 2u32);
}
```

## Fix

Pass one value for each payload field.

```actus compiles
enum Shape {
    Circle(u32),
}

verb main() {
    erg s: Shape = Shape.Circle(1u32);
}
```
