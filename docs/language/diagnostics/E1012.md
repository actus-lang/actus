# E1012: unknown parameter name in a call

A call with named arguments must use the parameter names that the verb
declares. The compiler does not guess which parameter a misspelled name was
meant to be. The message names the callee and the unknown name, and the error
points at that argument.

## Example

```actus fails=E1012
verb scale(abs value: Int, abs factor: Int) -> Int {
    return value * factor;
}

verb main() {
    erg a: Int = 2;
    erg b: Int = 3;
    print(scale(value: abs a, scale: abs b));
}
```

## Fix

Use the declared parameter name.

```actus compiles
verb scale(abs value: Int, abs factor: Int) -> Int {
    return value * factor;
}

verb main() {
    erg a: Int = 2;
    erg b: Int = 3;
    print(scale(value: abs a, factor: abs b));
}
```
