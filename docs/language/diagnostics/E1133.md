# E1133: role method implementation adds a capability

A role method lists the capabilities that its implementations may need. A
`perform` block may use fewer, but not more, so a call through the role
cannot hide a platform requirement (ADR-0096). The error points at the method
in the `perform` block.

## Example

```actus fails=E1133
struct File {
    value: Int,
}

role Writer {
    verb write(abs self: File) -> Int;
}

perform Writer for File {
    meta capability("posix.cloexec")
    verb write(abs self: File) -> Int {
        return self.value;
    }
}

verb main() {
}
```

## Fix

Declare the capability on the role method.

```actus compiles
struct File {
    value: Int,
}

role Writer {
    meta capability("posix.cloexec")
    verb write(abs self: File) -> Int;
}

perform Writer for File {
    meta capability("posix.cloexec")
    verb write(abs self: File) -> Int {
        return self.value;
    }
}

verb main() {
}
```
