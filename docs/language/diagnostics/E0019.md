# E0019: unsupported effect

`meta effect("...")` declares what a verb does besides computing a value. The
vocabulary is closed and registered in the compiler: `blocking`, `clock`,
`filesystem`, `network`, `allocation`, `entropy` and `volatile`. ADR-0091 says
that an unknown name is an error, with no escape hatch for user-defined
effects. The error points at the string.

## Example

```actus fails=E0019
meta effect("teleport")
verb main() {
}
```

## Fix

Use an effect from the list.

```actus compiles
meta effect("clock")
verb main() {
}
```
