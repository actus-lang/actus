# E1104: facade names a sibling that does not exist

A canonical facade exports the declarations of its siblings with a line
`open <name>;`. The name must be a file `<name>.act` in the same directory, or
a child directory with its own facade (ADR-0018). The compiler rejects a facade
that opens a name for which neither exists. The message names the module, its
facade and the missing `<name>.act`.

## Example

```actus fails=E1104 file=src/main.act
import shapes;

verb main() {
}
```

```actus file=src/shapes/shapes.act
open circle;
```

## Fix

Create the sibling file, or correct the name in the facade.

```actus compiles file=src/main.act
import shapes;

verb main() {
}
```

```actus file=src/shapes/shapes.act
open circle;
```

```actus file=src/shapes/circle.act
open verb area() -> Int {
    return 1;
}
```
