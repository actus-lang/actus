# E1803: compiler-owned standard library cannot be found

The runtime profile `std` is the compiler-owned standard library, and the
compiler finds it next to itself, not in the project (ADR-0041). This error
means the installation does not have it, or has it incomplete. It is an error
of the environment and of no file of the project, so it prints as
`error[E1803]: message`, with no path. The message is one of:

```text
error[E1803]: runtime profile `std` cannot locate the compiler-owned standard library
error[E1803]: builtin standard-library root has no package parent
error[E1803]: builtin standard library is missing its runtime registry
```

## Cause

A manifest selects `runtime = "std"` in `[build]`, and the compiler does not
find a directory `std/src` or `library/std/src` below `ACTUS_SYSROOT`, a
directory `../lib/actus/std/src` or `../share/actus/std/src` next to its
executable, or the `library/std/src` of the source tree it was built from. The
second and third messages mean that the directory was found, but the package
around it has no parent directory or its `Actus.toml` has no `[runtime]`
registry. A program cannot trigger this error on purpose, so it has no
example.

## Fix

Install the compiler again, or set `ACTUS_SYSROOT` to an installation that
holds the standard library. A project that does not use the standard library
can select `runtime = "core"`.
