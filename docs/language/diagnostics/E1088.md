# E1088: region element has no fixed native size

A `Region[T]` is a window onto elements that all have the same size, so `T`
must be a fully resolved type with a fixed native layout (ADR-0074). A
dynamic type such as `String` or `Buffer`, a nested region and `Void` have no
such size. The message names the element type. The error points at the type.

## Example

```actus fails=E1088
verb main(abs r: Region[String]) {
}
```

## Fix

Use an element type of fixed size, such as a fixed-width integer or a struct
of fixed-size fields.

```actus compiles
verb main(abs r: Region[u8]) {
}
```
