# E1087: stored value does not fit the element type

Storing into `values[i]` writes a value of the element type of the array. A
value of another type is rejected, because Actus has no implicit conversion.
An integer literal is accepted for any integer element type. The message
names the element type that the array holds and the type that was found. The
error points at the stored value.

## Example

```actus fails=E1087
verb main() {
    erg values: Array[Int, 4] = Array[Int, 4]();
    values[0] = true;
}
```

## Fix

Store a value of the element type, or change the element type of the array.

```actus compiles
verb main() {
    erg values: Array[Int, 4] = Array[Int, 4]();
    values[0] = 1;
}
```

```actus compiles
verb main() {
    erg flags: Array[Bool, 4] = Array[Bool, 4]();
    flags[0] = true;
}
```
