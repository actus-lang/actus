# E1030: field declared twice in a struct

The fields of a struct are identified by name, so each name can be declared
only once. The error points at the second field.

## Example

```actus fails=E1030
struct Point {
    x: Int,
    x: Int,
}

verb main() {
}
```

## Fix

Give each field its own name.

```actus compiles
struct Point {
    x: Int,
    y: Int,
}

verb main() {
}
```
