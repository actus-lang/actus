# E1141: call of a verb that returns nothing used as a value

A verb with no return type gives no value. Its call is correct as a statement
of its own, and it is an error where the program needs a value: a binding, an
assignment, an argument, an operand, a condition, a `return`, a conditional
value or a field initializer. The error points at the call, and the message
names the verb.

## Example

```actus fails=E1141
verb log() {
}

verb main() {
    erg value = log();
}
```

## Fix

Call the verb as a statement. If you need a value, give the verb a return
type and return one.

```actus compiles
verb log() {
}

verb main() {
    log();
}
```
