# E1072: pack field extends past the storage

Each field covers the bits from its `at` offset up to the offset plus its
width, and all of them must lie inside the backing store (ADR-0026). A field
that ends beyond the last bit is rejected before any code is generated. The
message gives the offset, the width and the capacity in bits. The error points
at the field.

## Example

```actus fails=E1072
pack Flags {
    erg storage: u8;
    layout little;
    fields {
        erg enabled: u1 at 0;
        abs _reserved: u8 at 1 = 0;
    }
}

verb main() {
}
```

## Fix

Shrink the field or move it, or choose a larger store.

```actus compiles
pack Flags {
    erg storage: u8;
    layout little;
    fields {
        erg enabled: u1 at 0;
        abs _reserved: u7 at 1 = 0;
    }
}

verb main() {
}
```
