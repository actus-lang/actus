# E0024: unterminated documentation string

A documentation string starts with `"""` and ends with the next `"""`. The
lexer reports this error when the file ends first. The error points at the
opening `"""`. Everything after it is part of the string, so the declaration
that follows is hidden until the string is closed.

## Example

```actus fails=E0024
"""
Entry point.
verb main() {
}
```

## Fix

Add the closing `"""` on its own line.

```actus compiles
"""
Entry point.
"""
verb main() {
}
```
