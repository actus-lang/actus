# E1036: unknown method

`receiver.name(...)` is a call of the verb `name` with the receiver as its
first argument (ADR-0029). The compiler reports this error when no verb of
that name exists. A verb that exists but cannot be a method is reported as
E1037, and a receiver of the wrong type is reported as E1038. The error points
at the call.

## Example

```actus fails=E1036
struct Point {
    x: Int,
}

verb main() {
    erg p: Point = Point { x: 1, };
    print(p.show());
}
```

## Fix

Declare the method as a verb whose first parameter is `self`, and call it on
a view of the value.

```actus compiles
struct Point {
    x: Int,
}

verb show(abs self: Point) -> Int {
    return 1;
}

verb main() {
    erg p: Point = Point { x: 1, };
    abs view = ref p;
    print(view.show());
}
```
