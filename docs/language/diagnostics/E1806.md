# E1806: strict build needs a verified LLVM toolchain

`actus build --strict` with the LLVM back end links the program with the LLVM
that the compiler was built against. Strict mode accepts only an LLVM that the
build verified against its recorded release (ADR-0041, ADR-0105), so a compiler
built against an LLVM of unknown origin cannot produce strict output. The error
is about the toolchain and not about a file, so it prints as `error[E1806]:
message`, with no path, and no output is written:

```text
error[E1806]: strict LLVM build requires a verified toolchain; selected prefix <prefix> is unverified; run scripts/bootstrap_llvm.sh or scripts/bootstrap_llvm.ps1
```

## Cause

The command is `actus build --strict` and the back end is `llvm`, from the
`backend` key of `[build]` or from `--backend llvm`, and the compiler was built
with an LLVM whose status is `unverified`, as `actus version --json` shows
under `llvm.status`. The prefix in the message is `LLVM_SYS_231_PREFIX`, or
`.actus-toolchain/llvm-23.1.2` when that variable is not set. A program cannot
trigger this error on purpose, so it has no example.

## Fix

Run `scripts/bootstrap_llvm.sh` (or `scripts/bootstrap_llvm.ps1` on Windows)
and rebuild the compiler against the verified toolchain it installs. Without
`--strict` the build is accepted.
