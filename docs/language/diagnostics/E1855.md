# E1855: function is above the hard size limit

A function has more than 80 code lines, the hard limit that strict mode
(`--strict`, ADR-0041) never accepts. Blank lines, `#` comments and `"""`
documentation blocks do not count. The message names the function and the
count, as in ``function `long` has 81 code lines; hard limit is 80``.

## Example

The comment `# catalog: repeat N` stands for N copies of the lines up to
`# catalog: end`, with `{n}` replaced by the copy's number. The example is 79
bindings `value_01` to `value_79`, so that `long` has 81 code lines.

```actus fails=E1855,strict
verb long() {
# catalog: repeat 79
    erg value_{n}: Int = 0;
# catalog: end
}

verb main() {
}
```

## Fix

Split the function into functions that each do one thing, and call them in
order.

When a long function is one operation that splitting would only scatter, such
as a state machine or a register setup sequence, mark it with
`meta limitless("verb")` (ADR-0048). The exception is then visible in the
source and in review.

```actus compiles strict
"""First part of the split function: it declares placeholder bindings and has no other effect."""
verb first_half() {
# catalog: repeat 40
    erg value_{n}: Int = 0;
# catalog: end
}

"""Second part of the split function: it declares more placeholder bindings and has no other effect."""
verb second_half() {
# catalog: repeat 39
    erg other_{n}: Int = 0;
# catalog: end
}

"""Entry point of the example; it does nothing and returns no value."""
verb main() {
    first_half();
    second_half();
}
```
