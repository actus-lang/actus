# E1130: bounded contract is exceeded or cannot be proven

`meta bounded(...)` states resource limits for a verb, such as
`max_iterations: 4u32` (ADR-0095). The compiler computes a worst case for the
body. Sequential work adds up, a branch counts as its largest arm, and a loop
multiplies its body by its proven count. The error is reported when:

- the worst case is larger than the limit;
- a loop has no proven bound, for example a range with a runtime end;
- the verb calls a verb that has no bounded contract of its own;
- the verb calls itself, directly or through other verbs.

The message names the dimension and the limit, and then what the body
requires. For the last two causes the message has fixed wording, such as
`recursive call path`, and the limit shown is `0`.

## Example

```actus fails=E1130
meta bounded(max_iterations: 4u32)
verb scan() -> Int {
    for erg index: u32 in 0u32..8u32 {
    }
    return 0;
}

verb main() {
}
```

```actus fails=E1130
meta bounded(max_iterations: 100u32)
verb scan(erg count: u32) -> Int {
    for erg index: u32 in 0u32..count {
    }
    return 0;
}

verb main() {
}
```

```actus fails=E1130
meta bounded(max_call_depth: 8u32)
verb down(erg n: Int) -> Int {
    return down(n: erg n);
}

verb main() {
}
```

## Fix

Raise the limit to the proven worst case, or make the loop count a fixed
value.

```actus compiles
meta bounded(max_iterations: 8u32)
verb scan() -> Int {
    for erg index: u32 in 0u32..8u32 {
    }
    return 0;
}

verb main() {
}
```
