# E0003: unexpected token

The parser reads tokens in the order the grammar allows. It reports this error
when the next token cannot continue the construct it is parsing. The message
says what was expected and which token was found, such as `expected
expression, found Semicolon`. The cause is usually a missing or extra token
before the one that is reported.

When the token that was found is the end of the file, the code is `E0004`
instead.

## Example

```actus fails=E0003
verb main() {
    erg limit = ;
}
```

```actus fails=E0003
verb main() {
    erg limit = 10
    erg other = 20;
}
```

## Fix

Write the missing part, or remove the extra token. In the first program the
binding needs a value. In the second the first statement needs its `;`.

```actus compiles
verb main() {
    erg limit = 10;
}
```

```actus compiles
verb main() {
    erg limit = 10;
    erg other = 20;
}
```
