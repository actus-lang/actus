# E1861: native call without a stack claim

The stack bound of a `meta stack_limit` verb includes the code it calls
(ADR-0103). The compiler cannot see inside an `unsafe extern` function, so
that function must state how much stack it uses, with its own
`meta stack_limit(bytes: N)`. The claim covers everything the native function
calls. The compiler trusts it and does not check it. The error points at the
call and names the function.

## Example

```actus fails=E1861
unsafe extern "C" verb native() -> Int;

meta stack_limit(bytes: 256u32)
verb run_native() -> Int {
    return native();
}

verb main() {
}
```

## Fix

Declare the stack claim on the `unsafe extern` function.

```actus compiles llvm
meta stack_limit(bytes: 128u32)
unsafe extern "C" verb native() -> Int;

meta stack_limit(bytes: 256u32)
verb run_native() -> Int {
    return native();
}

verb main() {
}
```
