# E1069: call to an unknown verb

A call must name a verb that is declared in the program, imported, or built
in. The compiler does not guess a name that is close to the one written. The
message names the verb. The error points at the call. A call to a verb that
exists but with wrong arguments has other codes.

## Example

```actus fails=E1069
verb main() {
    helper();
}
```

## Fix

Declare the verb, import it from the module that holds it, or correct the
name.

```actus compiles
verb helper() {
}

verb main() {
    helper();
}
```
