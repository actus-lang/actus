# E1092: constant remainder by zero

A remainder by zero has no result. When the divisor is a literal zero, or an
expression that the compiler evaluates to zero, the failure is certain, so it
is reported while compiling instead of trapping when the program runs
(ADR-0044). A divisor that is only known at run time traps when it is zero.
The error points at the divisor.

## Example

```actus fails=E1092
verb main() {
    erg n: Int = 10;
    erg m = n % 0;
}
```

## Fix

Use a divisor that is not zero.

```actus compiles
verb main() {
    erg n: Int = 10;
    erg m = n % 3;
}
```
