# E1117: constant declared twice

A constant has one name in its scope, and the name has one value (ADR-0052).
Declaring `const LIMIT` twice is an error, even if both declarations have the
same value. The error points at the second declaration.

## Example

```actus fails=E1117
const LIMIT: u8 = 1u8;
const LIMIT: u8 = 2u8;

verb main() {
}
```

## Fix

Remove one declaration, or give each constant its own name.

```actus compiles
const LOW_LIMIT: u8 = 1u8;
const HIGH_LIMIT: u8 = 2u8;

verb main() {
}
```
