# E1023: unknown type

A type name in a declaration, parameter, return type or struct field is not a
built-in type, a declared `struct`, `enum` or `pack`, or a type imported into
the module. ADR-0041 requires the compiler to reject unknown types instead of
guessing. The message names the type, and the error points at the declaration
that uses it.

## Example

```actus fails=E1023
verb main() {
    erg a: Wibble = 1;
}
```

## Fix

Declare the type, or import it, or correct the spelling.

```actus compiles
struct Wibble {
    n: Int,
}

verb main() {
    erg a: Wibble = Wibble { n: 1, };
}
```
