# E1029: struct declared twice

A module can hold only one struct with a given name. Two declarations would
give the same type name two layouts. The error points at the second
declaration.

## Example

```actus fails=E1029
struct Point {
    x: Int,
}

struct Point {
    y: Int,
}

verb main() {
}
```

## Fix

Rename one of the structs, or merge their fields into one declaration.

```actus compiles
struct Point {
    x: Int,
    y: Int,
}

verb main() {
}
```
