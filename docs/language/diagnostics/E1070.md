# E1070: pack storage is not unsigned fixed storage

A `pack` has a backing store whose size is fixed before the program runs. The
store is an unsigned integer of 8, 16, 32, 64 or 128 bits, or an
`Array[u8, N]` with a positive `N` of at most 8191 bytes. A signed integer, an
odd width such as `u12`, another array element type or a zero-length array
cannot back a layout whose bit positions are part of its type. The message
names the pack and the storage type. The error points at the storage type.

## Example

```actus fails=E1070
pack Flags {
    erg storage: i8;
    layout little;
    fields {
        erg enabled: u1 at 0;
        abs _reserved: u7 at 1 = 0;
    }
}

verb main() {
}
```

## Fix

Use an unsigned storage type of a supported width, and size the fields to
fill it.

```actus compiles
pack Flags {
    erg storage: u8;
    layout little;
    fields {
        erg enabled: u1 at 0;
        abs _reserved: u7 at 1 = 0;
    }
}

verb main() {
}
```
