# E0011: file-scoped limitless metadata in the wrong place

`meta limitless("file")` lifts the source-size limits for the whole file, so
it is a decision about the file and not about one declaration. ADR-0048 says
it must stand once, before every declaration. The parser reports this error
when it follows a declaration, or when it is repeated. The error points at the
declaration after the misplaced line.

## Example

```actus fails=E0011
verb main() {
}

meta limitless("file")
verb helper() {
}
```

## Fix

Move the line to the start of the file. To lift the limits for one verb only,
use `meta limitless("verb")` in front of that verb.

```actus compiles
meta limitless("file")

verb main() {
}

verb helper() {
}
```
