# E1102: module is both a file and a directory

A module has exactly one root. It is a single file, `src/shapes.act`, or a
directory with a canonical facade, `src/shapes/shapes.act` (ADR-0018). When
both exist for one name, the compiler cannot tell which one the name means,
so it rejects the module. The same error is reported for a child module that
has a directory and a sibling file of the same name.

## Example

```actus fails=E1102 file=src/main.act
import shapes;

verb main() {
}
```

```actus file=src/shapes.act
open verb area() -> Int {
    return 1;
}
```

```actus file=src/shapes/shapes.act
open circle;
```

```actus file=src/shapes/circle.act
open verb area() -> Int {
    return 1;
}
```

## Fix

Keep one root. Here the single file is removed, and the directory module
stays.

```actus compiles file=src/main.act
import shapes;

verb main() {
}
```

```actus file=src/shapes/shapes.act
open circle;
```

```actus file=src/shapes/circle.act
open verb area() -> Int {
    return 1;
}
```
