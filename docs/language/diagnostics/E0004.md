# E0004: unexpected end of input

The parser reports this error when the file ends before a construct is
complete. The usual cause is a missing closing brace or parenthesis. The error
points at the end of the file, and the message names the token the parser still
needs, as in `expected `}`, found Eof`.

## Example

```actus fails=E0004
verb main() {
    erg limit = 10;
```

## Fix

Close every block that was opened. An editor that matches braces shows which
one is still open.

```actus compiles
verb main() {
    erg limit = 10;
}
```
