# E0001: unexpected character

The lexer reads the source as a list of tokens. It reports this error when it
meets a character that does not start any token. Examples are `@`, `$`, a
backtick, or a character outside ASCII such as a typographic quote. The
character is reported as written, and the lexer goes on, so one stray
character does not hide later errors.

## Example

```actus fails=E0001
verb main() {
    erg total = 1 @ 2;
}
```

## Fix

Remove the character, or write the operator that was meant. Actus has no `@`
operator.

```actus compiles
verb main() {
    erg total = 1 + 2;
}
```
