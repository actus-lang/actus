# E0017: test metadata on a declaration that is not a verb

The test runner calls a test as an ordinary verb. ADR-0089 says that an
external declaration is not a test entry point, so `meta test` and `meta
fault` on an `extern` or `unsafe extern` declaration are rejected. The error
points at the declaration.

## Example

```actus fails=E0017
meta test
unsafe extern "C" verb c_abs(ins value: i32) -> i32;

verb main() {
}
```

## Fix

Remove `meta test` from the external declaration. If the call needs a test,
write an ordinary verb in the `tests` directory of a module that calls it.

```actus compiles
unsafe extern "C" verb c_abs(ins value: i32) -> i32;

verb main() {
}
```
