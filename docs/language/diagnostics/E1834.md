# E1834: rust source in the standard-library fixtures

The fixtures of the standard library, `library/std/tests/`, are Actus programs,
and the behavior they check is written in Actus. Rust test logic belongs in
`tests/` of the compiler repository (ADR-0041). `actus conformance` scans the
tree and reports each Rust file it finds there. The finding is about a whole
file, so it has no line and column: `<path>: error[E1834]: message`.

```text
library/std/tests/io/helper.rs: error[E1834]: Rust source is forbidden in `library/std/tests/` fixtures; note: Standard-library fixture behavior must be expressed as Actus source; Rust test logic belongs under `tests/`.; help: Move Rust integration logic outside `library/std/tests/` and keep the fixture in Actus.
```

## Cause

The command `actus conformance`, run in the root of the repository, finds a
file with the extension `.rs` anywhere below `library/std/tests/`. The command
exits with status 1 under `--strict` and with status 0 without it. No Actus
program can trigger it, so it has no example.

## Fix

Move the Rust file out of `library/std/tests/`, for example to `tests/`, and
express the fixture itself in Actus.
