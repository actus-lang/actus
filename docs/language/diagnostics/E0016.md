# E0016: fault metadata without test metadata

`meta fault("...")` asks the test runner to inject one failure into a test.
ADR-0089 says it must be paired with `meta test` on the same declaration, so
that a fault can never end up in production code. The error points at the
declaration.

## Example

```actus fails=E0016
meta fault("write_failure")
verb main() {
}
```

## Fix

A fault belongs to a test. In production code, remove the attribute. To test
how the code behaves under the fault, write a verb with both `meta test` and
`meta fault` in a file of the module's `tests` directory, as the testing guide
shows.

```actus compiles
verb main() {
}
```
