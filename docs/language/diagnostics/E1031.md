# E1031: unknown field of a struct

A struct literal or a field access names a field that the struct does not
declare. ADR-0041 requires the compiler to reject unknown fields. The message
names the field and the struct, and the error points at the field.

## Example

```actus fails=E1031
struct Point {
    x: Int,
}

verb main() {
    erg p: Point = Point { x: 1, z: 2, };
}
```

```actus fails=E1031
struct Point {
    x: Int,
}

verb main() {
    erg p: Point = Point { x: 1, };
    print(p.z);
}
```

## Fix

Use a field that the struct declares, or add the field to the struct.

```actus compiles
struct Point {
    x: Int,
    z: Int,
}

verb main() {
    erg p: Point = Point { x: 1, z: 2, };
}
```

```actus compiles
struct Point {
    x: Int,
}

verb main() {
    erg p: Point = Point { x: 1, };
    print(p.x);
}
```
