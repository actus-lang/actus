# E1120: result marked must_use is ignored

`meta must_use("reason")` marks a verb whose result the caller has to look at,
such as a status code (ADR-0090). A call to that verb as a statement of its own
throws the result away, and the compiler rejects it. The message repeats the
reason that the declaration gives. A result is used when it is bound, returned,
passed as an argument, used by an operator or propagated with `?`.

## Example

```actus fails=E1120
meta must_use("the caller must inspect the status")
verb write_frame() -> Int {
    return 0;
}

verb main() {
    write_frame();
}
```

## Fix

Bind the result and use it.

```actus compiles
meta must_use("the caller must inspect the status")
verb write_frame() -> Int {
    return 0;
}

verb main() {
    erg status = write_frame();
    if status != 0 {
        return;
    }
}
```
