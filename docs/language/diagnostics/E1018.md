# E1018: borrowed value returned as an owner

An `abs` parameter is a view of a value that belongs to the caller. A verb
that returns it as an ordinary value would hand out a second owner, or a view
that outlives its source. The compiler rejects this. It also rejects returning
a `ref` expression directly, and then the message says `temporary borrow`. A
verb may return a view only by declaring `-> abs`, and ADR-0021 then requires
that the view comes from exactly one `abs` parameter. The error points at the
returned expression.

A struct, an enum payload, an `Option` or a `Result` that holds a view follows
the same rule (ADR-0021, ADR-0046 2.3). It can leave the verb, as a return value
or stored through an `ins` parameter, only when every view inside it comes from
an `abs` parameter of the verb. A view of a local, of an `erg` or `dat`
parameter or of a temporary would dangle once the verb returns, so the message
names that source: `borrow `buffer` cannot escape its scope`.

## Example

```actus fails=E1018
verb pick(abs value: Buffer) -> Buffer {
    return value;
}

verb main() {
}
```

```actus fails=E1018
struct Window {
    abs bytes: Buffer,
}

verb open_window() -> Window {
    erg local: Buffer = Buffer[4];
    return Window { bytes: local, };
}

verb main() {
}
```

The aggregate can be built first and returned later. The views it holds are
remembered with the binding, and they are also carried by an aggregate that
moves into another one:

```actus fails=E1018
struct Window {
    abs bytes: Buffer,
}

verb open_window() -> Window {
    erg local: Buffer = Buffer[4];
    erg window = Window { bytes: local, };
    return window;
}

verb main() {
}
```

Storing such an aggregate in a field of an `ins` parameter is the same escape,
because the caller's object outlives the verb:

```actus fails=E1018
struct Window {
    abs bytes: Buffer,
}

struct Slot {
    erg window: Window,
}

verb fill(ins slot: Slot) {
    erg local: Buffer = Buffer[4];
    slot.window = Window { bytes: local, };
}

verb main() {
}
```

## Fix

Declare the return as a view. The result then borrows from the caller's
value and is never cleaned up by the callee.

```actus compiles
verb pick(abs value: Buffer) -> abs Buffer {
    return value;
}

verb main() {
}
```

For an aggregate, build it from an `abs` parameter of the verb, which the caller
keeps alive:

```actus compiles
struct Window {
    abs bytes: Buffer,
}

verb open_window(abs source: Buffer) -> Window {
    return Window { bytes: source, };
}

verb main() {
}
```
