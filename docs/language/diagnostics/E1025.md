# E1025: argument of the wrong type

The type of an argument must be the type of the parameter. Actus has no
implicit conversion between types, not even between integer widths. `Int` and
`u32` are different types. The message names the callee, the parameter and
both types, and the error points at the argument.

## Example

```actus fails=E1025
verb scale(abs value: u32) {
}

verb main() {
    erg n: Int = 2;
    scale(value: abs n);
}
```

## Fix

Pass a value of the declared type. Here the binding is declared with that
type.

```actus compiles
verb scale(abs value: u32) {
}

verb main() {
    erg n: u32 = 2u32;
    scale(value: abs n);
}
```
