# E1037: invalid receiver for a method

A verb is a method only when its first parameter is named `self` and has the
type of a declared struct (ADR-0029). A `self` parameter of another type, such
as `Int`, can never receive a method call, so the declaration is rejected. The
error points at the `self` parameter.

## Example

```actus fails=E1037
verb double(abs self: Int) -> Int {
    return 1;
}

verb main() {
}
```

## Fix

Give `self` the type of a struct, or rename the parameter if the verb is not
meant to be a method.

```actus compiles
struct Counter {
    n: Int,
}

verb double(abs self: Counter) -> Int {
    return 2;
}

verb main() {
}
```
