# E1805: runtime profile does not fit the target

The `freestanding` runtime profile is for programs that run without an
operating system, so it needs a target with a freestanding entry contract
(ADR-0041). A hosted target, which is the default, rejects it, as in
``runtime profile `freestanding` is incompatible with hosted target``. The
report names `Actus.toml` and the line and column of the `runtime` value, and
the code is the same with and without `--strict`.

## Example

```toml fails=E1805 file=Actus.toml
[package]
name = "app"
version = "0.1.0"

[build]
runtime = "freestanding"
```

```actus file=src/main.act
verb main() {
}
```

## Fix

Pick a profile that fits the hosted target, or select a freestanding target
for the freestanding profile.

```toml compiles file=Actus.toml
[package]
name = "app"
version = "0.1.0"

[build]
runtime = "core"
```

```actus file=src/main.act
verb main() {
}
```
