# E1095: assignment to an abs struct field

An `abs` field holds a read-only view that the struct does not own
(ADR-0046). It is set when the struct is built and then only read, so
assigning to it later is rejected. The message names the field and the
struct. The error points at the assignment.

## Example

```actus fails=E1095
struct Counter {
    abs total: Int,
}

verb main() {
    erg c: Counter = Counter { total: 1, };
    c.total = 2;
}
```

## Fix

Declare the field `erg`, or without a role, when it must change.

```actus compiles
struct Counter {
    erg total: Int,
}

verb main() {
    erg c: Counter = Counter { total: 1, };
    c.total = 2;
}
```
