# E1119: name is outside the scope of its module

Inside one unit, a directory module sees its own declarations, those of its
ancestors, and the exports of the children that its facade opens (ADR-0110).
Anything else needs an explicit import. A sibling or cousin directory is not
in scope, a child's private declaration is not in scope, and an import
written in a parent file is not inherited by its children. The message names
the name, the module that declares it, and the module that uses it. For a
directory that is out of scope, it shows the import that brings it in.

The error is also reported when a name is reached through an import of another
unit's child module and that child does not export it.

## Example

```actus fails=E1119 file=src/pkg/runtime/count.act
open verb width() -> u8 {
    return WIDTH;
}
```

```actus file=src/main.act
import pkg;

verb main() {
    erg width = pkg::width();
}
```

```actus file=src/pkg/pkg.act
open layout;
open runtime;
```

```actus file=src/pkg/layout/layout.act
open size;
```

```actus file=src/pkg/layout/size.act
open const WIDTH: u8 = 4u8;
```

```actus file=src/pkg/runtime/runtime.act
open count;
```

## Fix

Import the module that declares the name in a file of the module that uses
it.

```actus compiles file=src/pkg/runtime/count.act
import { open pkg::layout };

open verb width() -> u8 {
    return WIDTH;
}
```

```actus file=src/main.act
import pkg;

verb main() {
    erg width = pkg::width();
}
```

```actus file=src/pkg/pkg.act
open layout;
open runtime;
```

```actus file=src/pkg/layout/layout.act
open size;
```

```actus file=src/pkg/layout/size.act
open const WIDTH: u8 = 4u8;
```

```actus file=src/pkg/runtime/runtime.act
open count;
```
