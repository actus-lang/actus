# E1881: bundled linker does not match its contract

The compiler checks the bundled linker before it uses it: it must be LLVM LLD
23.1.2, and the toolchain manifest must name the compiler-runtime builtins of
the target (ADR-0041, ADR-0105). This error means the bundle does not match.
It is an error of the installation and of no file of the project, so it prints
as `error[E1881]: message`, with no path. The message is one of:

```text
error[E1881]: cannot verify bundled linker `<path>`: <reason>
error[E1881]: bundled linker `<path>` is not LLVM LLD 23.1.2: <version output>
error[E1881]: bundled toolchain has no builtins entry for target `thumbv7em-none-eabi`
```

## Cause

A project selects a freestanding ARM target, such as `target =
"thumbv7em-none-eabi"`, and names no linker, so the compiler uses the
`ld.lld` of its toolchain directory. Running `ld.lld --version` fails, or
prints a version other than `LLD 23.1.2`, or the `compiler_rt_builtins` table
of `share/actus/toolchain.json` has no entry for the target. A program cannot
trigger this error on purpose, so it has no example.

## Fix

Run `scripts/bootstrap_llvm.sh` (or `scripts/bootstrap_llvm.ps1` on Windows) to
replace the bundle with the verified one, or install the compiler again from a
complete release.
