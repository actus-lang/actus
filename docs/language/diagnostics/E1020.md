# E1020: break or continue outside a loop

`break` and `continue` act on the nearest enclosing loop (ADR-0043), also
from inside a `case` branch. Outside any loop there is nothing to leave or
repeat. The message names the keyword, and the error points at it.

## Example

```actus fails=E1020
verb main() {
    break;
}
```

## Fix

Put the statement inside a loop, or remove it.

```actus compiles
verb main() {
    loop {
        break;
    }
}
```
