# E1105: module source file cannot be read

The compiler reads every file of a module: the facade and its siblings. This
error means that the operating system could not read one of them. The message
names the file and the reason given by the system. The error is reported at
the start of the importing file, not in the file that cannot be read.

## Cause

The file exists, but its content cannot be read as text. The common causes
are:

- the file is not valid UTF-8, for example after an editor saved it in
  another encoding;
- the user who runs the compiler has no read permission on the file.

The error is reported for a file of a module. The same fault in the entry
file of the program is reported by the command itself, without a code, as
``cannot read `src/main.act` ``. A program cannot trigger this error on
purpose, so it has no example.

## Fix

Save the file as UTF-8 and give the user who runs the compiler read permission
on it. Then run the command again.
