# E1052: type parameter is not declared or not known

A generic declaration lists its type parameters in square brackets after its
name, as in `verb identity[T](...)` or `struct Box[T]`. A name that is neither
a declared type nor one of these parameters is reported with this code once
any generic parameter is in scope, where a plain declaration reports an
unknown type. The same code is reported at a call of a generic verb when the
compiler cannot find a type for one of its parameters, because no argument
fixes it and the call does not name it. The message then says `undeclared
generic type parameter` and names the parameter that stayed unknown. The error
points at the name or at the call.

## Example

```actus fails=E1052
struct Box[T] {
    erg item: U,
}

verb main() {
}
```

```actus fails=E1052
verb make[T]() -> Int {
    return 1;
}

verb main() {
    erg x = make();
}
```

## Fix

Declare every parameter that the declaration uses. At a call, write the type
argument in square brackets when no argument can fix it.

```actus compiles
struct Box[T, U] {
    erg item: U,
}

verb main() {
}
```

```actus compiles
verb make[T]() -> Int {
    return 1;
}

verb main() {
    erg x = make[Int]();
}
```
