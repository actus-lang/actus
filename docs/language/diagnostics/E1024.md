# E1024: verb declared twice

A module can hold only one verb with a given name. Actus has no overloading,
so a call is resolved by name alone. The error points at the second
declaration. A struct with a repeated name is reported as E1029.

## Example

```actus fails=E1024
verb run() -> Int {
    return 1;
}

verb run() -> Int {
    return 2;
}

verb main() {
}
```

## Fix

Rename one of the verbs, or remove the duplicate.

```actus compiles
verb run() -> Int {
    return 1;
}

verb run_again() -> Int {
    return 2;
}

verb main() {
}
```
