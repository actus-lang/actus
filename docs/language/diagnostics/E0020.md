# E0020: invalid bounded execution limit

`meta bounded(...)` states a resource budget as named fields, such as
`max_iterations: 1024u32`. ADR-0095 requires every value to be a literal with
an explicit width: `u32` for counts, and `u64` for byte budgets
(`max_allocation_bytes`, `max_stack_bytes`, `max_io_bytes`). The parser
rejects a value without the right suffix, a value that does not fit, an
unknown field and a field written twice. The message gives the reason.

## Example

```actus fails=E0020
meta bounded(max_iterations: 10)
verb main() {
}
```

```actus fails=E0020
meta bounded(max_laps: 10u32)
verb main() {
}
```

## Fix

Write the value with the suffix of its field, and use a field name from
ADR-0095: `max_iterations`, `max_call_depth`, `max_calls`, `max_allocations`,
`max_allocation_bytes`, `max_stack_bytes` or `max_io_bytes`.

```actus compiles
meta bounded(max_iterations: 10u32)
verb main() {
}
```

```actus compiles
meta bounded(max_calls: 10u32)
verb main() {
}
```
