# E1062: guard needs more than read-only access

A guard is written `Pattern if condition => body`. It decides whether a
branch applies, so it may only look at values (ADR-0016). It cannot move or
change a resource while it decides. The compiler therefore rejects a guard
that calls a verb or a method, builds a struct, indexes an array or contains
a `case` or an `if`, and a guard that reads a binding that is no longer live.
The message names the call, the name or the construct. The error points at it.

## Example

```actus fails=E1062
verb positive(abs n: Int) -> Bool {
    return n > 0;
}

enum Shape {
    Circle(Int),
    Dot,
}

verb area(abs s: Shape) -> Int {
    return case s {
        Shape.Circle(r) if positive(n: r) => 1,
        Shape.Circle(r) => 2,
        Shape.Dot => 3,
    };
}

verb main() {
}
```

## Fix

Write the test with operators on bindings and literals, or compute it before
the `case` and name it with a binding.

```actus compiles
enum Shape {
    Circle(Int),
    Dot,
}

verb area(abs s: Shape) -> Int {
    return case s {
        Shape.Circle(r) if r > 0 => 1,
        Shape.Circle(r) => 2,
        Shape.Dot => 3,
    };
}

verb main() {
}
```
