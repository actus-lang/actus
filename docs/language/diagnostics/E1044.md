# E1044: type contains itself without indirection

A struct or an enum cannot contain a value of its own type, directly or
through other types, because its size would be infinite. ADR-0046 allows a
recursive definition only when it stays finite, for example through `Option`.
The message names a type of the cycle, and the error points at the start of
that declaration.

## Example

```actus fails=E1044
struct Node {
    next: Node,
}

verb main() {
}
```

## Fix

Put the recursive field behind an `Option`.

```actus compiles
struct Node {
    next: Option[Node],
}

verb main() {
}
```
