# E1078: value mixes two arenas

Every value that is placed in an arena remembers which arena it came from
(ADR-0030). A reference into one arena cannot be placed into another arena or
combined with a value from another arena, because the first arena may be
released while the second one still holds the reference. The error points at
the value. The message calls a value that is being placed `placed value`.

## Example

```actus fails=E1078
struct Node {
    value: Int,
}

verb main() {
    erg first: Arena[64] = Arena[64]();
    erg second: Arena[64] = Arena[64]();
    erg a = first.place(value: Node { value: 1, });
    erg b = second.place(value: a);
}
```

## Fix

Place values that belong together in the same arena.

```actus compiles
struct Node {
    value: Int,
}

verb main() {
    erg first: Arena[64] = Arena[64]();
    erg a = first.place(value: Node { value: 1, });
    erg b = first.place(value: Node { value: 2, });
}
```
